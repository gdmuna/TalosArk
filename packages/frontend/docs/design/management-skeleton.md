# 管理中心页面骨架

## 资料与取舍

依据 `output/design/frozen-v2-71-2026-09-29/` 的生成计划、导航矩阵与 E/F 系列页面图，并同时应用 README 和 REVIEW-NOTES 的审阅限制。冻结图用于布局参考，不将示例数据与生成器添加的选项视为业务决策。

- 一级页面包含原有 15 个治理入口和后续新增的账户设置，并包含设计图明确呈现的局部视图导航；不包含独立的工作区详情、成员详情、授权详情、设施详情、事件详情等对象页面。
- 账户设置位于管理导航顶部，不带分类标题，属于当前账户而非组织上下文。资料编辑复用原用户菜单 Dialog 的账户数据源与更新行为；通知设置复用已有个人通知骨架，不添加未知的安全配置或新的账户 API。
- 冻结图中的独立管理二级侧栏被后续确认的分页主侧栏替代，不增加重复侧栏或一行 15 个页签。
- 设施是独立入口；组织归属与管理工作区分别呈现。存储设施治理是规则/拓扑上下文，不是样本格子。
- 共享策略只体现组织内部共享；权限只表达授予，不引入显式 Deny。
- 系统设置是组织治理设置，不重复个人账户主题或语言设置。
- 审计不提供编辑或删除操作；设备接入/集成不模拟真实硬件连接。

## 内容排版

`ManagementPage` 将页面级局部导航放在正文滚动区外，沿用工作台导航栏的固定高度与侧边距；其位置、宽度不受当前局部视图的内容宽度或正文滚动影响。集成详情内的页签属于详情区域，不提升到页面导航栏。

标题、操作和正文作为独立内容组居中。表单视图最大宽度为 768px；综合视图最大宽度为 1280px；列表视图按表格实际列宽收缩，并限制在父容器可用宽度内。表格列宽不为填满宽屏而拉伸，溢出由表格内部横向滚动承接。`ManagementPage` 拥有正文的主滚动容器，路由入口不再在外层重复包裹滚动区。

综合视图内部的多列布局按内容容器宽度切换，而非只按窗口宽度判断，以兼容侧栏展开和收起。概览中的工作区表格及通知策略的窄配置区也分别按其内容宽度居中。

## 数据与后续接入

骨架不是业务 API 实现，也不是新的通用管理业务模块。页面位于 `page/management/`，展示层小组件与表格列助手均为页面私有；未来按真实业务所有权提取成熟视图与数据源到相应模块，不把成员、设施、集成聚合成一个大 store。

目前只读取现有 workspace store 中已知的组织/工作区名称、标识、描述；这些仍由现有 mock adapter 提供。工作区总数按当前组织计算，不将列表数据推断为负责人、成员数、状态或更新时间。未知指标显示 `—`，其他记录、设置与健康状态显示未加载。策略表中的事件/资源分类和表单候选项是设计占位，不是生效配置或已经确定的 API 枚举；禁用控件也不代表当前策略关闭。

查询、排序、列可见性沿用 DataTable 的本地视图功能。新配置、邀请、授权、导出、保存和硬件连接操作禁用，不使用假成功反馈。现有 WorkspaceSwitcher 的 mock 创建/加入流程未改变。局部导航和集成类别切换等不涉及业务写入的 UI 操作可用。权限矩阵的动作、模板字段、日志字段、集成配置项与通知偏好均为设计骨架，不意味着相关 API 契约已经确定。

未添加 API、权限守卫或真实组织数据隔离。进入管理页面不等于拥有管理权限。后端接通后必须补齐加载/失败/空状态、权限检查、响应契约及写操作，未知值不能直接作为默认设置提交。
