# A02 设施存储节点分页规则收敛

日期：2026-10-20。状态：已实施。范围仅为 `module/facility` 的树和内容浏览器分页状态；不改变设施服务端契约。

## 决策与依据

`StorageBranch.vue` 和 `StorageBrowser.vue` 原先各自保存累计节点、游标和拓扑修订，并重复检查跨页修订、节点 ID 唯一性及游标是否前进。修改任一条跨页规则需要在两处核对，且两处已有不同的空页策略。将共同的快照接收和分页推进放入私有的 `model/useStorageNodePages.ts`，由每个视图实例各自持有状态；调用方仍负责具体查询和展示。

这项调整有实际收益：跨页修订、重复 ID 和游标推进规则现在只需维护一处，而树与内容区不会共享游标或互相污染。临时失败保留旧结果、权限/协议错误清除结果以及范围变化取消旧请求，继续复用既有 `useFacilityRead` 的语义；没有新增全局状态或对外接口。

## 保留的行为

- 树仍按父节点懒加载，每批 50 条；继续检查节点所属范围、父子关系、自指与祖先循环，并拒绝带后续游标的空页。
- 内容区仍每批 100 条；搜索、可用位置、列表/网格和节点深链维持各自查询及展示逻辑，原有空页策略不变。
- 两处都拒绝跨页修订变化、重复节点 ID 和不前进的游标。协议或权限错误清除累计结果；同范围临时失败保留旧结果，显式重新加载从首批开始。
- 上下文变化清除快照与游标，取消在途请求。设施数据源、路由参数、事件、后端及 contract 包均未因 A02 改动。
