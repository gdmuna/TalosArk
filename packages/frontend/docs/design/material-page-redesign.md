# 材料二级页面重做

## 已确认的方向

2026-10-09 用户确认采用“耗材、化学试剂、生物材料”三个产品业务分支。
培养物保留为生物材料中的专业对象 / 功能，删除独立的二级“培养物”页面、
导航与 `/main/material/culture` 路由。材料域只保留概览、材料列表。

这些是产品管理分支，不是严格互斥的科学分类，更不意味着恢复 MaterialType
的父子分类树。后端当前工作区拥有的扁平 MaterialType 不变。分支、用户分类
和专业能力是不同概念，正式接口中的对应关系仍需在材料业务切片中设计。

## 命名依据

- 培养物指向培养中的细胞或微生物等对象，其关注点包括培养条件、传代、
  冻存与复苏，不等同于培养所用的试剂。ATCC 分开描述细胞及培养维护过程、
  培养基、补充物和试剂。[ATCC 原代细胞培养指南](https://www.atcc.org/resources/culture-guides/primary-cell-culture-guide)
- “生物试剂”不适合作为培养物的新名字。培养基、血清等可以是培养用试剂，
  却不因此成为培养物；Gibco 将培养基、血清、补充物和培养试剂列为支持
  细胞培养的产品。[Gibco 产品资料](https://resource.thermofisher.com/page/gibcoinnovations/)
- “生物材料”在本产品中作为较宽的管理名称，容纳细胞系、菌株以及质粒、
  蛋白 / 酶、血清、培养基等。此范围是产品设计选择，不宣称是统一行业标准。
  示例中 DMEM、FBS、胰蛋白酶归入这一分支，但不具有培养能力。
- 实验室耗材可包括吸头、离心管、手套、培养器皿等，不等于所有实验器材。
  [Sigma-Aldrich 的实验用品目录](https://www.sigmaaldrich.com/US/en/products/labware)
  也区分了消耗品与设备等类别。本产品的耗材分支侧重常规包装、计量和库存台账。

建议区分材料定义、实体实例和培养对象：HeLa 细胞系是一种材料定义，
一管冻存细胞是实体库存实例，一瓶持续培养的 HeLa 对象具有培养生命周期。
不能把材料名称、某一瓶实体和传代事件压成同一种记录。

## 页面区域与组件映射

以 B-01、B-02 为结构参考，采用现有 Token、组件、主侧栏和 Sheet 约束，
不复制设计稿的虚构统计、常驻右侧 Inspector 或装饰性的浮动面板。

| 区域               | 实现                                                                      |
| ------------------ | ------------------------------------------------------------------------- |
| 二级导航与新建动作 | 固定 RouterTabBar；不随内容宽度或滚动变化                                 |
| 概览摘要           | 材料、关联实例、待检验三项；卡片有最大宽度，不无限拉伸                    |
| 概览左上 / 左下    | 最近变更、待检验材料；紧凑 Table，有完整字段结构，不附加 DataTable 工具栏 |
| 概览右上           | 三分支分布、材料类型数量；图表色稳定绑定分支，点击分支进入列表筛选        |
| 概览右下           | 纵向快捷操作；“查看耗材台账”打开同一列表的耗材筛选视图                    |
| 全部材料           | 现有 DataTable 的搜索、筛选、排序、列宽和可见性；主体保留列宽并整体居中   |
| 材料摘要           | 现有 SheetInspector；基础信息、分支属性、明确关联的库存实例、完整详情入口 |

名称 cell 的整格触发和 hover 下划线继续保留。分支、类型和状态的枚举筛选
明确传入 `mode: 'options'`。耗材、化学试剂、生物材料共用一个材料列表，
不是三个互不相通的台账或二级导航页。

## 数据与业务边界

页面仍消费公开的 workbench / workspace store。新增可选 `Resource.material`
摘要字段只携带显式分支、类型和培养能力，既不从名称 / description 推断，
也不假设后端已经具有该响应字段。只由现有 mock adapter 提供示例数据；
没有增加业务端点、独立数据源、写操作或兼容 API 层。

新增吸头与乙醇两条材料示例，以及一条明确关联吸头材料的包装实例示例，
均在 mock fixture 内，ID 含 `DEMO`，说明注明示例。没有编造库存余额、
纯度、CAS、检验结果、变更事件、更新时间或真实设备状态。

概览与列表的关联实例数量仅统计当前已加载摘要中的显式 `materialId` 关系，
不称为“可用实例”或完整库存余额。检验与活动记录保留未加载态，不能以 0
或“暂无待检验”冒充已完成查询。

Sheet 按分支展示不同属性结构：耗材的规格 / 包装规格，化学试剂的 CAS /
纯度或浓度，生物材料的来源 / 物种。属性值暂未加载，字段不构成后端
schema 更新。支持培养的生物材料才显示培养、谱系入口及 Cell Bank 文案；
普通耗材与化学试剂不获得这些专业入口。

耗材应复用材料定义、批次、实体包装、库存位置、领用 / 出入库、盘点、
阈值预警、审批与审计基座，而不是另建一套耗材库存模型。建议按实际
需要追踪箱、盒、包等库存实体，不强迫每支吸头都有独立实例；包装与基础
计量单位的换算规则应显式定义，不能靠名称解析。化学 / 培养专业档案在
后续领域模块内扩展，不塞进通用 Material 的必填字段，也不把培养工作流
默认为所有生物材料共有功能。

## 验证边界

未新增测试脚本。使用一次性 Playwright 命令检查真实 Edge 渲染、分支筛选、
Sheet 与详情 / 库存跳转、培养入口限制和工作区数据隔离。生产 Vite build
及定向 ESLint 必须通过；完整 vue-tsc 的旧测试缺失模块错误单独报告，
不以兼容占位、类型伪造或扩大排除范围掩盖。
