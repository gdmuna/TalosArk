## F05：导航描述与页面装配

管理和资源导航分别由 `router/management-navigation.ts`、
`router/resource-navigation.ts` 提供纯描述；相邻的 `management.ts`、
`resource.ts` 保留页面静态导入与 RouteRecord 装配。
侧栏、命令面板、业务页和面包屑上下文只读取描述，不再为取得名称或路径导入页面集合。
管理中心 Overview 改为读取描述，消除了原先经静态装配返回自身的运行时循环。

`module/workbench/navigation.ts` 集中既有路径、标签、tab ID 和命令元数据。
路由、Workbench 标签、概览入口、侧栏、用户菜单及命令面板从同一描述取得路径。
此描述是独立公共入口，不聚合到非视觉业务 index，也不承担页面或导航执行生命周期。

架构门禁允许消费者使用 module 的 `navigation.ts`，同 owner 使用相对实现导入；
导航描述不得导入 Vue 页面和路由装配文件。原 layer 与跨 owner 约束保留。

保持不变：所有路由静态导入、路径与 metadata、tab/command ID、文案和顺序；
管理中心默认账户设置；面包屑动作、快速返回来源、持久 Query 和一次性 Query 消费。
没有新路由框架、目录迁移或业务权限逻辑。

## F06：表格状态规则

`component/data-table/model/useTableModel.ts` 是私有状态 owner：
它组合 TanStack 受控状态、过滤定义、排序、分页与选择修剪，而不是只封装若干 setter。
DataTable.vue 仍负责呈现、预览、DOM 引用和既有 interaction/layout 的装配。
拖拽、Pointer resize、居中几何、边框 CSS 与混合滚动代码没有改写。

- 无操作列时，至少保留一个业务列；有操作列时允许隐藏全部业务列。移除操作列后重新校准。
- 选择列和操作列存在时保持可见；过滤与搜索辅助列保持隐藏。
- 列顺序去除未知、重复、技术列 ID，并补齐业务列；隐藏列仍保留其顺序。
- 尺寸默认值和上下限只有一处定义，存储与 resize 共用约束；总宽度直接取 TanStack 的可见列宽之和。
- min/max 更新时重新约束已保存尺寸，不引入动态 schema 迁移。
- 表头菜单与可见性面板共同使用 model 的隐藏判定和修改操作，不维护两份规则。
- 原始 `table` 与现有可变 expose 保留；TanStack setter 和暴露状态的直接修改都受到规则约束。
- 可变状态监听采用批处理，避免在数组原地 sort/splice 的中间状态修补顺序。
- 保留原来的排序/筛选/搜索/数据/pageSize 分页重置、过滤后选择清理，以及 offset/keyset 切换规则。

`DataTableApi` 从实际 expose 的对象推导，使用 Vue 的浅层 Ref 解包，与组件实例访问一致。
类型现已包含原先实际存在、但文档类型遗漏的 `table`；没有删除公共操作。

支持边界：同一挂载实例的业务 column ID 必须唯一且稳定。
标签与宽度配置可以更新；改变列身份须重挂载表格，不能假设旧筛选、排序、
wrapping 会自动迁移到新 schema。访问器或过滤语义变化的缓存迁移未纳入本轮支持保证，
需要重新创建相应表格上下文。本轮没有新增通用动态迁移机制或远程分页契约。
