# TalosArk 前端 UX 与交互规范

> 状态：v0.6，代码对齐基线。视觉 Token 见 [`design-foundation.md`](./design-foundation.md)。

## 适用范围与边界

本文说明设计基础应如何组成 TalosArk 的桌面端工作台。它不重复 CSS 数值；实际数值由 [`src/style.css`](../../src/style.css) 维护。

- `layout/` 负责应用壳层与空间骨架。
- `pages/` 负责路由入口与页面专属导航。
- `modules/` 负责可复用产品能力。
- `ui/` 只提供无业务语义的 shadcn-vue 基元。

## Desktop Workbench Shell

```text
Custom Title Bar (muted)
└─ Primary Sidebar (muted)
   └─ Primary Content Canvas (background)
      ├─ App Top Bar / Context Bar
      ├─ Page-local navigation
      └─ One intentional scroll owner
```

- Title Bar 与 Sidebar 是同一层级的暖中性 App Chrome；它们应比主内容 Canvas 略深，但不能抢夺业务内容的注意力。
- 主内容区域使用 `background`；Card、Popover、Dialog 等抬升内容使用 `card` / `popover`。
- 页面应明确唯一主滚动容器。壳层和中间布局节点负责约束尺寸与溢出，不应自然形成额外页面滚动。

## 导航与选择

- 一级 Sidebar 项在 Hover 时使用 `accent`；当前路由可用 `neutral-selected` 表示持久选择。
- 顶部或页面内 Router Tab 保持透明背景；未激活项的 Hover 文字由 `muted-foreground` 变为 `foreground`，激活项的 Hover 保持 `primary`。当前项以 `primary` 文字和底部指示线表现，不使用整块浅蓝背景。
- `data-[active=true]`、`data-[activated=true]` 表示持久状态，不能与 CSS `:active` 混用。
- 组织 / 工作区切换器是小型上下文选择面板，使用 Popover 容器；简单动作列表使用 Dropdown Menu。
- 侧栏由 `layout/sidebar/ApplicationSidebar.vue` 自定义实现，业务壳层不依赖 shadcn SidebarProvider / useSidebar。主壳层拥有展开状态，以 props / event 与顶部切换按钮共享，保留 `sidebar_state` 偏好 cookie 与 Ctrl / Cmd + B 快捷键。展开宽度 240px，收起为 56px 图标窄栏，宽度以 240ms 过渡；窄栏保留导航、搜索、工作区切换与最近访问。普通侧栏按钮通过 `SidebarButton` 统一图标、文字与提示策略，窄栏 Tooltip 向右显示且延迟为 0；工作区切换器的窄栏触发器沿用相同策略，不修改其他页面 Tooltip 的默认值。
- 工作区切换器与搜索保持在分页区域之外；工作区导航页与管理中心导航页共用左侧栏空间，以 280ms 横向滑动切换。管理入口位于工作区页底部，管理页底部提供“返回工作区”，分页区域顶部不重复显示管理中心标题；各页独立滚动，未激活页使用 inert / aria-hidden 并恢复到激活页的按钮焦点。管理入口打开上次管理页面；首次进入管理根路径，由路由重定向至账户设置，不在侧栏重复配置默认子页。返回时恢复上次工作区路由；直接访问管理 URL 与浏览器前进后退同步侧栏页及当前项。管理中心 15 个一级入口已接通页面骨架，写操作禁用；菜单、路由、面包屑与命令搜索共用入口定义。Reduced Motion 沿用全局规则。
- 管理页面只在设计图明确存在时增加局部视图导航，使用 URL 查询参数保留刷新与前进后退状态，不重复一级管理入口。页面级导航沿用工作台的固定高度与侧边距，置于正文滚动区外，不随局部视图内容宽度改变位置。集成详情区域的视图导航独立于集成管理 / 日志切换，并保留在详情区域。表单、列表和综合页面的标题、控件和正文分别按内容宽度限宽居中；表格保留实际列宽，综合布局按内容容器宽度响应侧栏变化。详见 `management-skeleton.md`。
- 展开侧栏时工作区切换器保留 `p-2` 的 ghost 按钮悬停留白，收起时内边距缓动到 0；名称、组织名与箭头保留 DOM 并淡出。标题栏应用标题的左外边距由 `ml-4.5` 缓动到 `ml-1.5`。侧栏宽度、按钮内边距、名称淡出与标题位移统一使用壳层提供的 `--sidebar-transition-duration: 240ms` 和 standard easing，反向切换时从当前值继续。工作区触发按钮与普通侧栏按钮保持同一个 DOM，以 Tooltip 的 disabled 状态控制窄栏提示，避免定位、焦点和文字过渡失效。
- 可折叠侧栏分组使用 `SidebarCollapsible`：展开侧栏时显示原有 Collapsible，标题不带左侧图标，箭头默认隐藏、悬停分组时显示、折叠后常显、展开后旋转；窄栏时仅保留图标触发器，点击在右侧打开带标题的 Popover，不将所有子项铺成图标。两种展示以与侧栏同长的 240ms 交叉淡入淡出切换，旧内容完成离场后再卸载，离场时立即设置 inert / aria-hidden，避免隐藏内容接收操作。两种展示复用同一内容插槽，保留此前的展开状态；切换回展开侧栏时关闭 Popover。从弹出层打开详情或命令面板时关闭菜单并将焦点交给持久触发器，避免浮层关闭后返回已卸载的菜单项。“最近访问”条目沿用纯文字与完整资源名称提示，“查看更多”保留右侧箭头的悬停淡入和位移效果。
- 壳层前进 / 后退使用 Vue Router 的浏览器 History，刷新后保留浏览器历史。`navigation` store 订阅路由与 `popstate`，更新按钮可用状态，不另建主导航内存栈。
- 工作台、材料、库存与设备共用 Router Tab 工具栏；二级导航靠左，页面操作放入右侧插槽，不新增重复一级标题。
- 全局搜索位于工作区切换器下方，使用 shadcn Command 与 Dialog，按材料定义、库存实例、设施、设备、文件、页面、命令分组。每项一行名称与通用 StateBadge，不显示编号；编号仍可用于搜索。资源与命令只消费当前工作区，不提供跨工作区搜索范围。方向键选择、回车执行和中文输入组合交给 Reka Listbox。
- 当前工作区由工作区切换器唯一决定。页面的查询、摘要、关联对象、详情与批量操作都使用 Store 的当前工作区集合，不提供额外工作区筛选。切换后清理详情、勾选与待确认的批量操作；清除表格筛选不改变数据范围。
- 当前工作区切换、搜索与工作台交互使用本地内存数据，刷新重置，不代表真实组织成员关系、资源权限或业务审批结果；接入 API 前需替换这些数据来源。

本地“加入工作区”演示邀请码为 `ARK-LAB2026`，对应苏州研究所的细胞成像平台；其他值用于验证失败状态。

## 控件交互

### Button

- `default` 是实线 Primary Action；`outline`、`secondary`、`ghost` 是中性操作层级；`destructive` 只用于危险操作。
- 默认 Button 只有 Hover、Focus、Disabled 和 Invalid 状态，不建立 `:active` 的按住态填充色。
- Primary Button 的实体 Hover 可以使用 `primary-hover`；其他按钮的 Hover 统一使用 `accent`。
- 普通操作 Button 的 Hover 不改变文字或图标的颜色；Router Tab 沿用上述导航专用 Hover 规则。选中项保持自己的前景色。四个一级导航图标始终不填充，激活时只使用 Primary 描边；分别使用 Lucide 的 LayoutDashboard、Shapes、Package 与 Microscope。
- 任何键盘可达 Button 都必须显示 `ring`；不要把 Focus 伪装成 Selected。
- Button 的 `useTooltip` 默认关闭，只由需要提示的图标控件显式开启；`tooltip` 仅负责提示文本，缺省时使用 `title` 或 `aria-label`。`tooltipSide` 默认 top，`tooltipDelayDuration` 默认 300ms，允许调用方覆盖，但不按业务位置隐式推断。`tooltipDisabled` 临时停用提示并关闭已打开的提示，不卸载触发器，用于需要稳定定位或焦点引用的控件。开启后采用 shadcn Tooltip 并移除原生标题浮层，普通文字按钮保留原有行为。共享 Button 不添加布局包装；程序自动聚焦不打开提示，键盘聚焦仍提供提示。拖拽开始时关闭提示，避免遮挡预览。

### Input 与表单

- Input Rest 使用 `background + input` 边框，Focus 使用通用 `ring`，Invalid 使用 `destructive`。
- `success`、`warning`、`destructive` 表示表单或业务结果，不能仅靠颜色传递状态；同时需要文字、图标或说明。
- 表单与设置中的单值下拉选择统一使用 shadcn Select；`modules/select-field` 同时提供 Trigger 的可访问名称和菜单顶部的 `PopoverTitle` 主标题，不将分组用的 `SelectLabel` 用作整个菜单的标题。表格每页条数选择器不渲染菜单标题与其分隔线，仍保留可访问名称。表格的枚举筛选在 Dropdown Menu 中使用带方框的 shadcn Checkbox，复选框与整行均可切换，点击后保持打开；不将表单 Select 用作筛选工具栏。
- Select 默认使用 `popper`，菜单沿 Trigger 下边缘展开，保留 6px 间距；空间不足时自动翻转或限制高度，不使用默认 `item-aligned` 覆盖 Trigger。动作菜单与筛选菜单同样需要顶部视觉锚点，子菜单通过 Portal 避免被父菜单裁切。
- 侧栏与用户菜单共用 `WorkspaceSwitcher` 的可搜索 Popover；选择用户菜单的工作区入口时立即关闭菜单并在用户按钮下方打开工作区面板，不再维护另一套子菜单。面板行高为 32px，组织标题与列表间留 4px 间距，移除容器叠加间距；右上角“工作区管理”关闭面板并打开管理中心的工作区列表，模块只发出 manage 事件，由应用布局负责路由。面板受可用视口高度约束，列表最高 256px，内部滚动，搜索与底部操作固定。
- Popover 的开合动画消费 Reka 的 `data-state=open/closed`，用户菜单转入工作区面板时退出与进入动画同时进行，不等待菜单退场结束。
- CollapsibleContent 统一提供 150ms 高度与透明度动画；Reduced Motion 沿用全局规则。

### 工作台概览

- 总览是当前工作区的行动入口，摘要计数由当前待办、待审批申请和未处理异常集合派生，不使用独立模拟统计或没有可核对来源的环比。
- 待办按截止时间从早到晚排列，申请优先展示较早的待审批记录，异常先按严重度再按发生时间排列。有限预览与“全部”入口进入对应业务页面；记录入口携带 ID 打开现有详情 Sheet，不在概览复制审核或处理流程。
- 入口 URL 中的预览或定位指令只执行一次：执行前通过 replace 清理对应参数，保留其他查询参数、hash 和返回上下文，不新增历史项。预览开合使用本地状态，清理参数不关闭预览；后退或刷新不重放指令。搜索、筛选分支与局部视图等持续状态不按指令清理。
- 业务页面导航与实例切换立即显示目标内容，不播放整页淡入、淡出或位移动画，不保留离场页面层；内容与其面包屑上下文一同替换。侧栏、弹层与拖拽排序保留各自的组件级动效。
- 最近访问只解析当前工作区的资源，复用资源详情入口；缺失关联对象不生成伪记录。各区域提供明确空状态。内容区整体居中，摘要卡固定宽度，队列使用无框分区与单行分隔，不将分区包装为嵌套卡片。

### DataTable 与 Inspector

- `modules/data-table/DataTable.vue` 使用 shadcn Table、Checkbox、Input、Select、Button 和 TanStack Table v9。默认客户端分页；排序、筛选、搜索重置页码，数据变化时修正越界页码并移除不可选记录。
- 工具栏左侧显示“筛选”入口与启用条件数量、多字段“排序”入口与字段数量，右侧保留搜索；不显示特定列的条件标签。“列可见性”以带 Tooltip 的横向省略号放在固定操作列的表头，替代操作列标题；无操作列的表格才保留工具栏入口。属性内部多选采用 OR，不同属性采用 AND；空选项集合移除条件。枚举二级菜单使用真正的方框 Checkbox，支持点击整行或复选框，点击后保持打开；标题左侧提供全选 / 取消全选复选框，部分选中时显示半选。“清除全部筛选”和“清除此列筛选”均使用右上角垃圾桶按钮，空条件时禁用；前者保留搜索文本，搜索框提供独立清除按钮。
- 一级筛选条目使用固定的图标、属性、条件摘要和箭头列，摘要左边缘与宽度一致；未设置条件显示“不限”，长条件截断并通过悬停标题提供完整值。字符串二级筛选在输入框旁常显“包含”匹配方式，一级摘要也保留该匹配方式；日期文本匹配格式化显示值，不通过输入占位文字单独表达匹配规则。
- 筛选菜单底部分隔线固定为 1px，上下各留 2px，不参与指针交互。表格日期与详情时间通过 Day.js 统一显示为 `YYYY/MM/DD HH:mm:ss`，使用用户本地时区和 24 小时制；排序与日期范围判断仍使用原始时间戳，日期文本包含筛选使用同一格式化字符串。总览的紧凑摘要保留相对时间。
- “我的待办”的今天 / 已逾期属于截止时间条件，与状态条件共用同一筛选机制，不再单独维护一组筛选按钮。任务状态按表格显示分为互斥的“待处理”“已逾期”“已完成”；“已逾期”由未完成任务的截止时间派生，不改变原始业务状态。默认明确勾选待处理与已逾期，保留全部未完成任务；取消已逾期后排除逾期记录。表内截止时间使用普通前景色，逾期由状态 Badge 表达。日期选项计数以当前工作区任务集合为基数。
- 整块业务表头按钮打开统一列菜单，包含升序 / 降序 / 清除排序、仅针对该列的筛选、隐藏、自动换行开关和重置列宽。表头保留语义图标和 `aria-sort`，不显示拖拽把手、排序方向或冻结状态图标；Hover 背景变化表达可交互状态。表头升序 / 降序会覆盖整个排序配置，只使用对应字段。
- 工具栏排序器可添加多个不重复字段、切换字段与方向、删除条件或清除排序；按列表从上到下的优先级组合排序，把手可拖拽或使用上下方向键调整优先级。列可见性面板共用相同的列表重排交互，同时切换各业务列显示；“全部显示”恢复可见性，不重置列顺序。
- 每个表头与数据 cell 独立绘制四边完整格框，不依赖相邻格提供边界；相邻格框精确重合为单像素线，保留原有列宽、行高与内边距。表头拖拽时仅隐藏源表头内容，当前页所有数据单元格（最多 100 行）保留显示并跟随预计位置移动。普通列表重排仍采用整项虚影。列宽拖动通过 Pointer Capture 接收鼠标与触摸，按实际边界位置补偿居中布局位移；跨越居中与横向溢出边界时继续跟随光标，受最小 / 最大列宽约束时停止。
- 表头、排序优先级与列可见性共用拖拽动画生命周期：完整条目虚影在开始时淡入并轻微抬起，位置直接跟随指针；其他条目在插入位置变化时以 160ms 补间让位，释放时落位，取消时返回，随后清理虚影。预计落位处显示低透明度、虚线边框的完整条目，位于各自容器的普通条目下层，不使用全局高层级或蓝色辅助线。拖动中只预览位移，释放后才提交顺序；以虚影中心与未动画的布局锚点判定换位，保留实际抓取偏移。拖拽期间统一接收有效容器的进入与经过事件，子元素切换不撤销接受状态；容器之外不可放下。规则使用稳定身份，键盘重排同样提供位置过渡。表格不移动选择列与固定操作列；位移只更新 transform，滚动或尺寸变化时更新锚点，关闭弹层或卸载时取消并清理。Reduced Motion 跳过 JS 补间。视图控件的菜单标题旁提供可悬浮或点击的问号 Tooltip，说明设置仅对当前用户生效；批量操作和记录操作会修改共享数据，不使用此说明。
- 总页数不超过 1000 时，分页器显示每页条数与可输入的页码；每页可选 5、10、20、50、100 条。页码使用文本 Input + numeric inputmode，不显示原生数字步进按钮；输入合法整数后回车或失焦跳转，拒绝超出当前页数或 1000 页边界的值。首页 / 上页 / 下页 / 末页保持固定尺寸并在不可用时禁用。
- 总页数超过 1000 时整表切换为连续浏览，隐藏页码、总页数、首页与末页，只提供上页 / 下页。明确提示“结果超过 1000 页，已切换为连续浏览”，并建议缩小筛选范围。当前是基于已加载、已排序记录 ID 的内存游标演示，不是远端分页；接入后端时须由数据源提供不透明游标，不能将内存位置当成后端 offset。
- 空表在跨列单元格中渲染 shadcn Empty。筛选条目与表头共用 `DataTableColumn.icon`，筛选条件通过相同列 ID 关联图标，不另建重复图标配置或统一替换成筛选漏斗。
- 异常与提醒顶部的统计卡片只展示本页摘要，不附加筛选或选中行为；筛选操作集中在表格工具栏。
- 内部记录 ID 不是业务编号，不放入表格主信息或关联对象单元格，也不用于成功通知。详情标题与关联对象名称附近使用 `ID: XXX` 显示完整 ID，XXX 为文本按钮，Hover 时出现下划线并带 Copy 图标，统一使用 `CopyableId` 点击复制；复制成功仅向辅助技术与按钮提示提供确认，失败明确提示。UUID 等长 ID 必须换行，不能撑宽 Inspector。
- 每个业务表头注册语义图标，公共组件的图标保持可选。待审批数量列、操作列和分页页脚均左对齐；其他领域列仍按明确的列配置对齐。每个列边界显示竖线，数据单元格背景不因 Hover 或选择而变化，选中由复选框表达。
- 行操作通过 `actions` 注册，`primary` 详情为常显的主色文字 Button，不是图标按钮；其他操作放入竖向省略菜单。批量能力单独通过 `bulkActions` 注册及判断整个选择集合的可用性；未注册的动作不得自动批量化。当前普通任务可批量完成、申请可批量批准，未处理的异常与提醒可批量标记已处理或忽略；异常批量操作在写入前校验整个集合。成功不显示额外通知文字，错误仍需可见。
- 选择计数、批量动作、取消选择与筛选处于固定高度的同一工具栏，空间不足时横向滚动，不增加纵向选择栏。仅操作列永久固定在右侧，不可隐藏、换序或调宽，不提供用户冻结配置；选择列与业务列正常滚动。操作列覆盖其他内容时，在单元格左侧外缘使用 16px 连续渐隐，过渡与列边界精确衔接，不增加半像素或一像素偏移，不补画硬分隔线或内阴影；未覆盖时沿用相邻列边框。表体上下及工具栏不添加滚动边缘分隔线，边界由单元格和外框边框表达。
- 业务列保持配置宽度，调宽只改变目标列；表格外框随实际列宽收缩且包含两侧边框，不渲染空白补齐列，也不因边框产生无意义的溢出。列边界支持鼠标 / 触摸拖动调宽、双击重置，尊重领域的最小 / 最大列宽；调宽把手不进入键盘焦点序列。自动换行默认开启，领域可通过 `wrap: false` 显式关闭，用户可在列菜单切换。
- 表头与数据单元格的水平内边距统一为 10px；选择列单独居中且整个单元格可点击。业务页第一数据列的整格均可打开详情，Hover 或键盘聚焦时主标题显示下划线；单元格背景保持不变。
- 我的待办、待审批、异常与提醒的概览、工具栏和表格作为一个业务内容区，在主容器内整体居中，不分配剩余空间来拉宽列；窄屏受父级可用宽度约束。概览卡片保持固定宽度，不主动拉伸铺满同行。
- 表格默认由内容自然撑高，不占满父容器高度；受最近有界父级的剩余高度约束时，表体内部纵向滚动，表头与页脚保留。记录区默认最小高度为三行（`minRows`），按首条可见记录的实际行高测量，空状态沿用最近的行高；尚无记录时采用 57px 的默认行高。显式 `minHeight` 预留表头、页脚和横向滚动条后，向上取整到完整行数；`maxHeight` 可显式覆盖自动约束。空状态占满整个记录视口。父级连最小高度都无法提供时，由父级承担剩余页面滚动。表体采用真正嵌套的双容器：外层原生容器接收横向溢出，内层 ScrollArea 接收纵向溢出，覆盖式纵向滚动条不挤占列宽；不使用模拟滚动条或双向同步。操作列与纵向滚动条保持在横向可视右边缘。两个视口均启用原生平滑滚动，减少动态效果偏好下关闭。Inspector 在所有宽度统一使用有界高度的 Sheet，不挤占表格宽度；中部 ScrollArea 由领域调用方提供，不由公共组件自动添加。
- 待办是个人行动队列，待审批是申请审核队列。审批类待办通过 `approvalId` 关联同一申请，其状态从申请派生；不能通过“完成任务”绕过审批。退回或批准后个人队列同步更新，普通任务独立完成。
- 列与筛选器由领域提供，单元格通过 `cell-{id}` 插槽定制。`query`、`filters`、`selected` 可用 `v-model`；公开 `table`、分页、排序、列宽、顺序、可见性与换行状态、`resizeColumn` 辅助函数、当前页 / 筛选后 / 已选数据及清空辅助函数。选择全部指当前页可选记录，跨页选择保留在当前筛选集合内。

### 用户菜单

- 用户菜单使用 Dropdown Menu，依次展示账户身份、当前组织 / 工作区上下文、账户设置 / 我的待办 / 关于应用、独立分隔的退出操作。工作区入口立即打开与侧栏一致的分组选择面板，并取消旧菜单退场后的自动焦点恢复；旧菜单关闭时立即设置 inert，防止退场中的 pointer-leave 处理再次聚焦旧菜单。焦点交接标记保留至旧菜单卸载，即使面板已快速关闭，也不让旧菜单抢回外部操作的焦点，重新打开菜单时重置标记。面板明确标记当前项，使用 Escape 关闭后恢复用户按钮焦点，外部点击则保留目标焦点。
- 账户设置是管理中心顶部不带分类标题的一级入口，包含个人资料与通知设置局部视图；用户菜单与顶部设置按钮共用该路由入口。资料保存后更新头像首字与显示名称，取消更改恢复当前账户值。个人通知复用现有骨架，未接入的数据与写操作保持禁用。
- “关于璇玑云库”首次打开时聚焦可编程聚焦的标题，不自动突出关闭按钮；保留焦点约束、键盘关闭和入口焦点恢复。
- 当前账户资料通过 `account-profile` store 与注入的数据源维护，开发数据由 `module/account/data/mock.ts` 提供。名称编辑只更新内存数据，刷新重置；退出沿用导航至登录页的现有行为，未替代后端会话撤销。

### Overlay

- Popover 和 Dropdown 是不改变主布局的临时表面。
- Dialog 与 Sheet 是覆盖层，不挤压 Main Content；Dialog 用于聚焦决策，Sheet 用于上下文详情或可延展操作。
- 桌面外壳在自定义标题栏下方提供独立 Portal 容器，其布局包含块约束 Dialog / Sheet 与遮罩的 fixed 定位；不在公共组件硬编码标题栏高度。标题栏不被遮挡或蒙层覆盖，操作窗口控件不触发浮层的外部点击关闭。无外壳 Provider 时仍挂载到 body。
- Overlay 中的 Close 仍有 Hover 与 Focus，但不添加按住态。

### 滚动边缘

- `modules/scroll-surface/EdgeBoundary.vue` 是无滚动逻辑的视觉原语，支持四个边缘和 `fade` / `line` 两种效果；`line` 为 1px 分隔线，渐隐宽度默认 16px。渐隐透明度在 0% / 20% / 40% / 60% / 80% / 100% 位置分别为 0% / 8% / 32% / 68% / 92% / 100%，仅在边缘终点完全覆盖表面色，不设置实色平台。通过 `active` 切换显示，使用 `--edge-surface` / `--edge-line` 匹配表面颜色，不拦截指针与辅助技术。
- `ScrollSurface` 将 ScrollArea 与边缘状态组合，`edges` 可选择纵向、横向或双轴，也可用 `top` / `bottom` / `left` / `right` 数组单独指定边缘；`edgeEffect` 可关闭边缘效果。键盘滚动留白按启用的边缘分别计算，不为未启用的边缘预留空间。共享 `ui/ScrollArea` 只暴露实际视口与覆盖层插槽，不默认附加视觉效果或业务依赖。边缘状态由滚动与尺寸变化更新，不逐帧测量布局；渐变只绘制窄边缘，不使用背景模糊滤镜。
- 工作台及资源页主滚动区、侧栏列表、工作区列表和详情面板采用渐隐；重排列表、枚举选项及页面导航采用分隔线。命令面板的搜索结果仅启用顶部 1px 分隔线（`edges=['top']`、`edgeEffect='line'`），底部不添加边缘装饰。表格仅在操作列覆盖内容时，于该列左侧外缘使用渐隐；表体上下及工具栏不附加滚动边缘装饰。

## Visual QA

每次修改 `style.css` 或基础组件时，至少检查：

1. 暖中性壳层与主内容 Canvas 的层级是否仍清晰。
2. 普通 Hover 是否只使用 `accent`，而不是浅蓝或业务状态色。
3. Selected 是否为持久语义，而非鼠标按住。
4. 图表色是否与成功、警告、失败语义分离。
5. Focus、Disabled、Invalid 与 Reduced Motion 是否仍可访问。

`color-system-preview.html` 可用于快速人工校色，但它是派生预览；验收基础组件时应优先查看真实 Vue `Button`、`Input`、Sidebar、Tab 和 Overlay。
