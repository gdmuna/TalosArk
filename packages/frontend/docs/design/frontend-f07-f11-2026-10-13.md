## F07：滚动与避让

以下记录首次实施配置；同日的方向修正见本节末尾。

原来的固定 `36px` 不属于所有滚动区域的默认行为，但用户确认它是命令面板的合适值。
因此新增 ScrollSurface 的 `focusInset`（默认 0），只对 `edges` 指定的边生效。
各边 scroll-padding 为效果宽度加额外避让：fade 默认 16px、line 1px、none 0。
`none` 不再隐式产生上下 36px，但允许调用方主动配置额外避让。

命令面板显式传入 `focusInset=36`，仍然只启用顶部 line，因此顶部 37px、底部 0。
不调整渐变曲线，不恢复表格上下装饰，不为所有弹出层增加命令面板的空间。

ui/ScrollArea 新增无业务语义的 `viewportStyle`，直接传给自己的 viewport。
ScrollSurface 删除外层 CSS 变量与深层 viewport 选择器，避免父层滚动避让污染嵌套区域。
axis 与 ScrollBar 继续遵循原 primitive 的组合：横向调用方提供横向 ScrollBar。
DataTable 仍采用原生 X 与 ScrollArea Y 的两个容器，不强制迁入 ScrollSurface。

### 同日修正：上下焦点避让不对称

用户实测发现向下导航没有额外留白。复现结果为顶部 scroll-padding 37px、底部 0px，
最后一项贴底，而首项距离顶部 36px。根因是额外 focusInset 被装饰 edges 过滤，
命令面板仅开启 top 装饰，因此 bottom 避让被关闭；此前验证了首尾未裁切，
但未断言两方向都保留指定距离，漏掉了这一行为。

隔离对照还确认：仅把底部 scroll-padding 改为 36px，末项也只能留出 16px，
因为到达最大滚动范围。为列表末尾补足内容空间后，末项距离变为 36px。

现将 focusInset 与装饰独立：数字统一设置四边，对象可单独设置 top/bottom/left/right。
命令面板使用 `{ top: 36, bottom: 36 }`，仅 top 保持 line，实际 scroll-padding 为顶部 37px、
底部 36px、横向 0。CommandList 的底部内容 padding 使用同一 bottom 值，
确保末项有可用的滚动空间；ScrollSurface 不擅自改变任意调用方的内容布局。

补测 1440×1000 与 1000×560：End 后末项、ArrowDown 导航的中间项底部距离均为 36px，
ArrowUp 导航的中间项顶部为 37px，Home 后首项顶部仍为 36px。
仅一条顶部装饰；空结果、Escape、独立按边配置与嵌套视口隔离通过。
类型检查、定向 ESLint、生产构建通过；无新增持久测试脚本。

### 同日纠正：避让不应改变内容布局

上述补足末尾空间的实现超出用户要求：它把键盘滚动避让误作永久内容 padding，
普通滚动到列表底部时出现了 44px 空白。现已移除新增的 36px 内容 padding，
恢复 CommandList 原有 8px 内边距，仅保留独立的上下 scroll-padding。
焦点在可滚动范围内仍按指定距离对齐；首尾由原生范围自然约束，
不再要求最后一项始终保持完整 36px，也不使用动态 padding 或额外占位元素。
补测：底部实际空白从 44px 回到原有 16px（列表与分组各 8px），
ArrowDown 中间项仍留 36px，ArrowUp 中间项仍留 37px，末项按范围收敛到 16px。
生产类型检查、定向 ESLint、构建和 whitespace 检查通过。

### 同日修正：长按导航的平滑滚动重启

用户选择保留单次平滑、长按即时保视的局部方案，不是把所有键盘导航改为即时滚动。
Reka 每次高亮切换仍执行原有 scrollIntoView；原生 smooth 被重复事件不断重启，
隔离页面中 35 次连续向下切换出现最高约 797px 的高亮项视口溢出。

源码只修改 CommandPalette.vue：用已有 ScrollSurface.viewportElement 暴露获取视口，
在 Command 的 keydown 捕获阶段识别 repeat，同步切换该视口的 scroll-behavior 为 auto。
单次导航不强制新的动画策略；keyup、focusout、window blur、open 变化及 scope 释放
恢复之前的 inline 值和 important 优先级。同步写入必须先于 Reka 的冒泡处理，
不能依赖 Vue 下一次渲染才改变滚动行为。未修改 Reka、公共 ScrollArea/ScrollSurface，
未增加节流、事件重放、动画引擎或内容 padding。

实际页面补测：连续上下各 35 次导航，各有 34 个 repeat 调用走 auto，
高亮项视口溢出均为 0，松键后恢复 smooth；Reka 调用仍为 block=nearest。
松键、失焦、window blur、关闭、重开、原 inline important 恢复通过；
隔离挂载的真实 CommandPalette 卸载后，捕获的旧视口样式也恢复。
搜索、IME、Enter 页面导航、空结果与 Escape 通过，无 pageerror。
生产类型检查、定向 ESLint 和生产构建通过，保留既有 chunk 体积警告。
未运行旧全量测试套件，未新增持久测试脚本，未纳入并行 auth 联调修改。

## F08：表格几何

新增私有 `component/data-table/layout/geometry.ts`，集中三类既有知识：

- 祖先高度约束：找到 ScrollArea viewport、明确 height/max-height 或 overflow 约束。
- 居中容器：识别作者设置的 auto margin；实际像素位置和宽度决定当前是否仍处于居中状态。
- cell 内部格框：结合布局透明边框与 `::before` 格框，计算定位虚影的各边 inset。

Typed OM 保留 authored auto 值；没有该能力时仍只用 inline style 作原有限 fallback。
不把 resolved margin 的像素值反推为 authored auto，也不引入通用布局框架。
高度、整行 minRows、实际列边缘反馈、最多三次 resize 校准与 0.5 居中补偿保留。
拖拽虚影的尺寸、低层级定位与虚线 inset 保留，本轮不再重写动画或边框。

## F09：本地视图 Query

`platform/navigation/useQuerySelection.ts` 只处理选择与路由历史机制。
management/resource helper 保持原来的返回接口；label、培养能力和可用 tab 仍归页面。

- 当前 URL 的有效字符串决定视图，缺省/非法/数组值回退默认，不自动发起跳转。
- 无效 setter 不执行；有效的不同视图使用 push。
- 默认值从 URL 省略；已经规范的重复选择不跳转。
- 显式选择当前 fallback/default 时使用 replace 清理非法或冗余参数，不添加历史。
- 保留其余 query（包括数组）与 hash；可使用独立 queryKey，不互相覆盖。

持久 `view/q` 与一次性 `resource/task` 等命令仍为不同机制。
不增加整页动画、不改变快速返回来源或 breadcrumb 的业务动作。
