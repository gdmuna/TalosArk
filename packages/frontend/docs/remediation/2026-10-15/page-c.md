# C 组：库存与位置

共 9 张稿。Facility、设备、StorageNode/容器/位置必须区分；材料定义条数不等于库存数量，转移不等于数量调整。

## C-01 库存概览

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-01.png) · `/main/inventory/overview` · [源码](../../../src/page/inventory/Overview.vue)

- **图中构图**：顶部库存摘要，下方左侧最近流转/常用材料，右侧存储占用、风险和临期，优先引导到具体问题。
- **当前差异**：四项未知指标和若干空区块，暂无实际库存聚合，构图缺乏有用内容支撑。
- **整改**：用固定宽度摘要表达库存对象数、可用量或风险等明确口径；跨单位不能相加成一个总数量。最近流水展示对象、操作、数量/单位、位置、人、时间；风险只列可处理项。
- **交互**：摘要进入 C-02/C-07 带筛选；位置风险进入 C-03 对应节点；临期跳有期限的具体批次或实例。
- **依赖**：P09/P16/P17；布局可先在隔离预览验证，生产不能拼装静态成功统计。
- **验收**：多单位、零库存、暂无风险、部分数据失败分别成立；占用率分母来自真实容量。

## C-02 库存列表与 Inspector

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-02.png) · `/main/inventory/ledger` · [源码](../../../src/page/inventory/Ledger.vue)

- **图中信息**：库存/实例编号、材料、批次、位置、状态、数量、入库信息；选中后能读到物料与位置的完整关联。
- **当前差异**：主要复用泛 ResourceList，不足以承载数量、批次和位置结构。
- **整改**：独立库存列定义与读模型，第一列编号+材料名；数量右对齐/单位绑定，位置路径分层截断并可展开；状态、可用量、预留量分开，按实际库存模型展示。
- **交互**：首 cell Sheet；入库、领用/归还、转移分别进入 G-07/08/09；“详情”进 C-09。批量菜单只注册已定义的安全动作，不能在未选时使用。
- **依赖**：P09/P11/P13，库存行对象是什么需随实际契约核对，不把材料汇总行与物理实例行混成一表。
- **验收**：过滤/分页/计数同源；不同批次同材料、不可移动状态、无位置、共享只读库存均可辨认；刷新后选择和路由不串对象。

## C-03 存储浏览·Facility-Freezer

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-03.png) · `/main/inventory/storage-topology` · [源码](../../../src/page/inventory/StorageTopology.vue)

- **图中构图**：左树定位设施/存储层级，中间查看当前设备关联的存储结构，右侧选中节点事实和存量摘要。
- **当前差异**：三块框架存在，但选择主要是泛设施资源，无真实 StorageNode 树、节点容量和布局。
- **整改**：采用 1440px 工具画布；树约 240px、中央 `minmax(0,1fr)`、属性约 280px；不足时折叠属性到 Sheet。中间先实现清晰二维层架/抽屉/盒布局，不复制仅有装饰意义的冰箱透视图。
- **交互**：树、面包屑、中央选中同步；展开不触发选中混乱；节点详情明确 Facility、关联设备、管理工作区、容量与占用；库存操作必须选实际目标位置。
- **依赖**：P08/P09；存储结构治理属于 F-08，不把库存浏览的“编辑”变成绕过治理规则的入口。
- **验收**：有树无库存、无容量节点、过深路径、无权子节点、空 Facility、树搜索和直接节点深链；占满不自动表示设备故障。

## C-04 存储浏览·Box-Position

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-04.png) · 同存储浏览路由，建议 query `node` 保存选中位置容器。

- **图中构图**：左侧层级保留，中间有行列坐标的盒/孔位网格，右侧具体选中孔位与内容；上方容量与状态图例。
- **当前差异**：没有位置网格实现，不能用一个“布局待加载”块算通过。
- **整改**：按真实规格渲染行列，cell 尺寸稳定、有坐标和状态文字/图标，不单靠红绿。小屏网格局部滚动；不为所有盒写死 9×9 或 96 孔。
- **交互**：键盘方向键切格、Enter 查看、Esc 清选择；空位可进入入库，已占位查看/转移；多选范围和批量能力需明确，不能默认框选即移动。
- **依赖**：P08 位置规格/容量/占用查询与 P09/P11 的一致性保护；预检“空位”不是提交时的占用保证。
- **验收**：1 格/非正方形/稀疏位置、占用刚变化、保留/不可用孔位、无权限孔位；坐标/详情/提交目标严格一致。

## C-05 盘点任务

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-05.png) · `/main/inventory/stocktake` · [源码](../../../src/page/inventory/Stocktake.vue)

- **图中构图**：任务列表为主，辅以近期活动和选中任务范围/进度；进行中任务有“继续盘点”，已完成任务有结果入口。
- **当前差异**：空任务表和查询视图只是骨架，无范围/进度事实。
- **整改**：列任务名/编号、范围（Facility/节点）、负责人、计划/开始时间、进度、差异数、状态；状态与进度不能凭日期猜。视图 `all/进行中/已完成` 的具体 query 值沿用源码，不重置用户链接。
- **交互**：新建时明确盘点范围和参与者；继续到 C-06 保留任务 ID；完成只能看结果，不出现可编辑扫描框。
- **依赖**：P14 首发取舍待确认；无任务不能显示“已盘点 0，差异 0”的假成功摘要。
- **验收**：草稿/进行中/待复核/完成/取消按真实状态集合设计；并发加入、离开和权限变化有可理解反馈。

## C-06 盘点执行工作区

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-06.png) · `/main/inventory/stocktake/:taskId` · [源码](../../../src/page/inventory/detail/StocktakeExecution.vue)

- **图中构图**：任务头、四阶段步骤、盘点摘要、扫描/输入工具、预计与实盘差异表、选中行录入、底部保存/提交复核。
- **当前差异**：prepare/count/review/complete 可自由切换的 Tab 和只读扫描输入不是流程实现，可能误导用户以为切 Tab 就推进状态。
- **整改**：步骤条表达服务端状态与可执行动作，页面浏览状态独立于任务状态；中央表保留期望/实际数量与位置差异，选中编辑区宽度稳定；底部动作只固定于工作区，不压住原生 X 滚条。
- **交互**：人工输入可先用，不强依赖扫码硬件；草稿保存、未保存离开提示、提交确认、冲突刷新和差异原因必需；复核确认后才产生调整流水。
- **依赖**：P14 盘点状态机、并发/调整/审计；“完成”按钮不能直接覆盖库存数。
- **验收**：断网编辑、草稿恢复、重复扫码、数量 0、错位置、同一记录并发修改；复核失败不丢录入，刷新不会重放调整。

## C-07 库存预警

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-07.png) · `/main/inventory/alert` · [源码](../../../src/page/inventory/Alert.vue)

- **图中信息**：低库存/临期/异常等分类，材料/风险/当前值/阈值/工作区/负责人/处理状态；右侧查看来源规则与库存。
- **当前差异**：空表和固定分类没有真实规则/事件，当前值与阈值可能单位不同。
- **整改**：风险类型、严重度、处理状态分开；低库存显示数量+单位，临期显示日期/剩余天数，不把它们塞进同一无单位数字列；来源规则摘要与历史放 Sheet。
- **交互**：确认/忽略/去处理由实际规则提供；不能用“去领用”作为低库存的通用解决动作；调阈值需要治理权限，不在只读提醒 Sheet 偷开。
- **依赖**：P16 与库存来源；与工作台异常、通知中心可共享事件引用，但不是重复建三套提醒状态。
- **验收**：事件仍在但已确认、库存恢复后的历史、规则停用、阈值缺失、只读人员；颜色映射全局一致。

## C-08 库存流水

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-08.png) · `/main/inventory/transaction` · [源码](../../../src/page/inventory/Transaction.vue)

- **图中信息**：时间、类型、对象、数量变化、位置、操作者，选中后看来源申请和变化依据。
- **当前差异**：空表缺乏入库/领用/归还/转移/调整各自的展示规则。
- **整改**：数量变化有正负与单位；位置迁移显示单一 from→to；只改位置的转移数量差为 0 仍是有效操作，不显示成“无变更”。流水号、请求号可复制，来源可跳转。
- **交互**：不可直接编辑/删除已产生流水；筛选类型、日期、对象、操作者；Sheet 有理由、前后数量/位置、来源单据和审计关联。
- **依赖**：P09/P11/P12；库存流水不是后端错误日志，也不直接使用 Audit JSON 代替业务账本。
- **验收**：部分领用、跨位置转移、调整负数、取消申请无执行流水、重复请求不会产生重复流水；时间区显示一致。

## C-09 库存实例详情

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/C-09.png) · `/main/inventory/detail/:resourceId` · [源码](../../../src/page/inventory/detail/Detail.vue)

- **图中构图**：对象头含实例/材料/批次/数量/位置全路径；概览/流转/文件标签；左侧事实，右侧位置小图与最近流转。
- **当前差异**：事实列表存在，布局预览/历史/文件多处空占位，缺实例专属读模型。
- **整改**：1280px 主辅详情；关键数量/状态/位置在第一屏，材料和批次都可进入真实详情。位置小图只显示该对象所属局部位置，不加载整个组织拓扑。
- **交互**：三个 view 分别查询事实、只读流水、授权附件；转移/归还带当前实例参数，执行后位置与历史一起刷新。
- **依赖**：P09-P11/P10；位置未知和未入库是不同状态；资源不存在不显示父材料的详情。
- **验收**：深链、换资源 ID、无权限、占用变更、已使用完、无附件；当前状态与历史最后一笔账一致。
