# D 组：设备

共 9 张稿。软件首发可先做设备台账与关联；实时遥测、控制后台和真实硬件联动是下一阶段，不用假曲线/假回执冒充已实现。所有设备页明确区分连接状态、运行状态、告警状态与数据新鲜度。

## D-01 设备概览

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-01.png) · `/main/equipment/overview` · [源码](../../../src/page/equipment/Overview.vue)

- **图中构图**：总量/在线/告警摘要；24h 告警趋势与状态分布、关键设备监测、健康表和维护信息。
- **当前差异**：未知摘要、空健康表、监测占位；没有可证实的遥测来源。
- **整改**：第一屏突出“需要查看哪些设备”；健康表含名称/位置、连接、运行、最近数据时间、告警数；趋势有明确窗口与单位，不画平直假线。摘要不因少于四项就无限拉伸。
- **交互**：告警摘要到 D-03，设备行到 D-04，维护到 D-07；无遥测的台账设备显示未接入，不算离线故障。
- **依赖**：台账随设备业务切片；遥测/趋势/实时健康为阶段保留。
- **验收**：在线但数据过期、无心跳、手动维护、未配置来源四种状态均不同；图表失败不影响台账导航。

## D-02 设备列表与 Inspector

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-02.png) · `/main/equipment/list` · [源码](../../../src/page/equipment/List.vue)

- **图中信息**：设备名称/编号/类型/状态/位置，选中摘要显示监测值、关联资源与常用动作。
- **当前差异**：泛资源列表能预览名称，但无法表达设备连接/遥测/控制能力差异。
- **整改**：名称+编号首列，类型分类色；连接、运行、告警分别展示；位置优先人可读 Facility/区域路径，最新数据时间可见。Sheet 只放核心事实和少量指标/入口。
- **交互**："查看详情"进入设备对象而非泛列表；登记接入对应 F-09；操作按钮依据能力和授权，不依据设备名称硬编码。
- **依赖**：台账与能力目录契约；遥测缺失不阻塞基本列表。
- **验收**：无图片、未知状态、长位置、共享只读、未绑定控制后台设备；未接入不得冒充在线。

## D-03 设备告警

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-03.png) · `/main/equipment/alert` · [源码](../../../src/page/equipment/Alert.vue)

- **图中构图**：活动/恢复/全部视图，严重度、设备、事件、发生时间、状态；选中看当前值/阈值、生命周期与确认记录。
- **当前差异**：静态视图和空表没有真实告警生命周期。
- **整改**：严重度与处理/恢复状态独立；确认人、恢复时间、最后采样时间按需呈现；Sheet 上方事件事实，中部时间线，下方允许动作。
- **交互**：确认仅记录已知悉，不自动宣告故障恢复；去设备运行页保留事件；工作台同源事件不重复维护状态。
- **依赖**：P16 软件提醒可复用呈现，设备事件源属下一阶段。
- **验收**：已确认未恢复、已恢复未确认、重复上报归并、来源离线、旧数据越阈值，均不误报成功。

## D-04 设备详情·运行状态

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-04.png) · `/main/equipment/detail/:resourceId?view=runtime` · [源码](../../../src/page/equipment/detail/Detail.vue)

- **图中构图**：完整设备头与五标签；关键指标带、24h 大趋势与监测表为主栏，操作/基本信息/最近告警为辅栏。
- **当前差异**：有头和标签，运行面板仍是空事实/图表/告警骨架。
- **整改**：1280px 主辅布局；温度/设定值/门状态等来自真实能力，不给所有设备套冰箱模板。曲线显示单位/采样时间、断点和缺测；常用操作不过度抢占第一屏。
- **交互**：时间窗口、系列选择与缩放可用；进入控制台有明确范围；查看告警带事件引用，返回保持设备/窗口。
- **依赖**：阶段保留，实时源和历史查询均需契约。
- **验收**：空序列、稀疏/过期数据、不同设备能力、趋势局部失败、连接中断不错误显示最后值为当前值。

## D-05 设备详情·设备信息

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-05.png) · 同设备详情 `?view=information`

- **图中构图**：基本身份/规格/所属位置为主，关联 Facility、连接配置摘要、支持能力和使用情况为辅。
- **整改**：按身份、制造/型号、归属/责任人、安装/维护信息分组；设备与存储节点关系有明确链接；没有字段就不填“默认型号”。
- **交互**：编辑只有实际有写 API/权限才可用；配置摘要不暴露凭据；独立设备所有权与管理工作区，不用当前工作区替代归属。
- **依赖**：台账契约可先做；使用统计额外查询，不从命令列表当前页推算。
- **验收**：未绑定设施、多个合法关联、字段缺省、长序列号、不支持某类能力时排版仍整齐；保留同一对象头。

## D-06 设备详情·绑定关系

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-06.png) · 同设备详情 `?view=binding`

- **图中构图**：关联类别摘要与绑定清单，含目标对象、类型、用途、状态和操作。
- **整改**：分类 tabs/筛选不与对象五标签混成一层；表明确关联 Facility、StorageNode、材料/实例或控制后台的关系名称和方向。
- **交互**：查看跳到对应对象；绑定/解绑需要说明对存储/控制的影响。不能把关系解绑等同删除设备或变更资源所有权。
- **依赖**：关联模型与授权；不是发现 Prisma 外键就能自动开放管理按钮。
- **验收**：失效关系、目标不可见、解绑被占用阻止、同目标不同关系，不吞掉业务限制错误。

## D-07 设备详情·维护记录

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-07.png) · 同设备详情 `?view=maintenance`

- **图中构图**：维护列表、选中记录的执行人/类型/时间/结论/附件，以及下次计划信息。
- **整改**：维护计划和已发生记录分组；日期、负责人与结论可扫读；报告链接复用 P10 文件能力，不把整篇记录直接塞单元格。
- **交互**：登记维护不自动发送硬件命令；编辑/撤销需保留历史，不无声改掉过去结论；从逾期维护提醒能定位记录。
- **依赖**：台账扩展/维护业务需要单独确认，软件记录可先于硬件实现。
- **验收**：无计划、有记录无附件、延期、被取消计划、操作者已移除，均不误显示正常完成。

## D-08 设备详情·命令历史

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-08.png) · 同设备详情 `?view=command`

- **图中构图**：命令类型/日期筛选、命令编号、发起人、时间、结果；选中后区分请求、下发、回执及详情。
- **整改**：状态按实际阶段表达排队/接收/执行/成功/失败/超时等，具体枚举以契约为准；详情显示 request/dispatch/receipt 时间与脱敏 trace 关联。
- **交互**：重试只有幂等策略和权限定义后开放；返回信息结构化展示，隐藏密钥、连接串、未知厂商原始错误内容。
- **依赖**：下一阶段命令系统；不能拿 HTTP 200 或 API accepted 生成“执行成功”。
- **验收**：请求成功但未下发、回执晚到、超时后成功、重复请求、权限撤销；历史不可直接编辑。

## D-09 设备操作控制台

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/D-09.png) · `/main/equipment/detail/:resourceId/console` · [源码](../../../src/page/equipment/detail/Console.vue)

- **图中构图**：当前运行摘要在上，操作配置在左，实时反馈/最近命令在右；危险动作有独立警示与确认。
- **当前差异**：空配置与禁用按钮不是可操作控制台，不能宣称硬件已接通。
- **整改**：工具画布分主操作与结果；字段从能力 schema 生成可读控件，数值有单位/范围；只读状态与可修改参数分开，最后数据时间始终可见。
- **交互**：G-10 二次确认显示设备、参数、工作区和后果；提交后使用命令 ID 跟踪状态，不自动重发；离开页面不等于取消已发出的命令。
- **依赖**：明确下一阶段；前端可独立预览布局，生产不能让模拟回执串进真实台账。
- **验收**：不支持能力、断线、参数无效、危险操作取消、提交成功但断网、回执失败；同一设备上下文不可被切换污染。
