## 组件边界

- `InventoryStockInspector` 归库存 module，供台账、材料实例、库存详情摘要复用；独立按 ID 读取、切区清选择、失败可重试，没有生产 Mock 回退。
- `InventoryMovementList` 只呈现流水快照并发出选中事件，供概览和实例详情复用；查询与写入仍归原 owner。
- `MaterialInspector` 归材料 module，供概览与列表共享按 ID 读取的预览；`MaterialInventoryPanel` 是材料详情私有的页面组合，装配材料批次、库存分页与入库，不上移为通用组件或改变业务 owner。
- Facility 的 `node-content` 插槽提供节点上下文，库存页面私有 `InventoryPositionContent` 装配库存与入库。Facility 不依赖 inventory；只有当前活动工作区与浏览范围相符时挂载该组合。
- `ResourceObjectHeader` 增加可选副标题、状态 tone、摘要插槽，原返回上下文不变。其他调用方类型检查通过，不代表其业务页一并完成。
- `SelectField` 显式渲染当前选项的响应式标签，修复异步 UUID 更新成名称后触发器保留旧文本的问题；model 与选中规则不变。
- `CopyableId` 允许按钮收缩，使长 ID 在窄属性栏换行，复制图标留在边界内；复制行为不变。
- 不重写 DataTable、拖拽、认证、权限或路由；新增文件保持单数命名。

入库文件较大的文本差异主要来自 Sheet / 独立滚动区包裹后的模板缩进。本次增加可选材料 / 批次 / 位置预填；如已有待恢复操作，原始请求优先，不能被新的入口覆盖。登记、冲突、重放和同步恢复函数未改。位置父级在表单确认同步并关闭后才刷新，避免提前卸载表单导致回执未确认。
