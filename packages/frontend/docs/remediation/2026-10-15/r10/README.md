## 实现边界

- 保留认可的紧凑摘要、1200px 居中画布、3:2 主辅分栏与无装饰卡片的内容区。
  未有真实工作队列时展示已落地的材料、库存、设施，不把旧示例统计或队列挂回生产。
- 复用各业务的公开 HTTP 适配器；应用入口只组合读函数，不增加客户端可写的总快照。
  工作台独立按当前工作区加载，不加入应用启动必需阶段，不拖累其他业务页。
- 材料使用概览提供的有效总数和最近更新；库存使用服务端总量及最近入库；
  设施使用当前工作区权限范围内未归档设施。分页项数量不当作总数。
- 当前没有真实最近访问记录来源，不把“最近更新”冒充“最近访问”。
- 403、请求失败、真实空列表和未接入分别呈现；某一区域故障不能隐藏其他区域。
- 切换组织/工作区、退出、重新登录、页面销毁与重试均取消旧读取，迟到结果不得发布。
- 导航进入已有业务详情；写入仍归业务页面与后端，不在工作台重复实现权限或库存规则。
