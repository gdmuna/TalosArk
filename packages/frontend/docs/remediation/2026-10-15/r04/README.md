## R04-A1 实施边界

1. 分别逐张核对 F-11、F-12。保留“筛选列表 → 事件预览 → 完整详情”的信息层级，使用现有 DataTable、SheetInspector、ScrollSurface 和管理页区块，不复刻旧稿重复侧栏、玻璃背景或卡片墙。
2. `module/audit` 只拥有读数据源契约、可取消读取和范围校验，不依赖 workspace/team 数据源，也不要求启动时加载。列表/详情视图负责当前账户、组织、工作区和路由组合。
3. URL 保存组织/工作区、已提交动作/资源/时间条件、容量和当前不透明游标；输入草稿不触发查询。时间下界含、上界不含。切换筛选/范围清游标，详情返回恢复列表 URL。
4. 游标页显示本批条数、返回首批和下一批，不伪造总量、随机页码或对当前批次做全局搜索。DataTable 仅增加自定义 footer 插槽与可隐藏的搜索框，既有调用默认行为不变。
5. 列表首项打开 Inspector，主详情进入 `/main/management/audit-log/:eventId`。Inspector 重新读取单事件，不把列表摘要当成完整详情。详情头全宽，正文居中；不添加路由过渡动画。
6. 只展示公开投影字段及动作白名单解释后的字符串事实，不接收或渲染任意 `details`。无来源的结果、IP、客户端、事务号和通用前后值不展示。缺失操作者不推断为系统事件。
7. 组织/工作区/账户/查询改变时同步清旧数据并取消请求；即便来源忽略取消，迟到结果也不能发布。401/403/404、认证变化及范围错误清旧记录；临时故障可保留同范围上次结果并明确提示，重试只重读。
8. 关联资源暂只显示事件时名称和 ID，不根据历史快照推导当前访问权限或拼链接。当前可读性查询及跳转仍由 A2 接通。导出归 P18，本轮不放假可用按钮。
