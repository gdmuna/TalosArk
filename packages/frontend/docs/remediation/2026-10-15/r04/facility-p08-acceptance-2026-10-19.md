## 交付范围

| 入口 | 当前交付 |
| --- | --- |
| F-06 设施列表 | 组织范围、服务器搜索/状态/分页、独立预览、创建、显式权限初始化 |
| F-07 设施详情 | 真实身份/位置/管理工作区/节点数、基本资料编辑、生命周期、USE/MANAGE 授予调整撤销、结构浏览 |
| F-08 存储治理 | 懒加载树、节点独立深链、列表/坐标网格、创建/编辑、批量孔位、同级锚点排序、空子树移动与生命周期 |
| C-03/C-04 存储浏览 | 当前工作区的真实设施/节点读取、路径定位、稀疏网格与授权位置候选；选用后显示路径/ID，可取消 |
| 工作区详情 | 同一设施来源的管理/共享关系与设施预览，不新建平行来源 |

创建时检查服务端 canCreate 与 canGovern，设施治理使用 govern，节点维护使用 manage，候选选择使用 usable。不根据角色名计算权限。设施属于组织；管理/共享工作区关系不等于内部库存内容访问权。

每设施只有一套当前拓扑。容器支持任意层级，POSITION 为叶节点，坐标从 1 开始且行列成对。网格仅显示已登记节点，不将不存在的格子解释为空位。批量提交最多 1000 个明确位置；排序只提交 beforeNodeId；跨设施空子树移动携带来源和目标 revision，保留节点身份。

## 逐稿与组件设计

分别单张核对冻结稿 F-06、F-07、F-08、C-03、C-04。保留设施列表、对象头/局部导航、左树/中央结构/节点详情、盒内坐标定位的信息层级；采用现有管理画布、DataTable、Inspector、Dialog、SelectField、StateBadge、CopyableId 和 ScrollSurface。没有照搬旧稿额外侧栏或添加虚构的设备、容量、库存统计。

对象头与局部导航仍在全宽顶部，正文居中；结构工具最大 1440px。存储浏览按容器宽度从三栏退为两栏或上下布局，网格局部滚动，稀疏网格的行列轨道固定为 48px。没有新增路由动画、深色主题或拓扑切换功能。

`module/facility/data` 从公开 Schema 推导类型、复用 HTTP 客户端并验证身份/范围/分页；`model/read` 维护取消、快照、冲突及写后同步；`ui` 共享树、选择器、浏览器和结构表单。页面只组合组织/工作区、URL 与预览。`main.ts` 注册真实 HTTP adapter，不在启动阶段读取设施，不回退 fixture。调用映射见 [当前契约交接](facility-read-contract.md)。

## 失败、并发与上下文

- 所有业务调用禁止自动重试；认证屏障仍由既有平台与 auth owner 负责。
- 409 保留表单草稿、阻止再次提交，显式刷新后才允许用户确认保存，不自动覆盖或重放。
- 写入成功但重读失败仍视为已提交；提示“操作已成功，数据尚未同步”，暂停后续写入，恢复入口只重新读取。
- 账户、组织、工作区、设施或节点范围变化同步清快照并取消旧请求；即使来源忽略取消，旧读写完成也不能发布到新上下文。
- 同范围临时读失败保留明确标记的旧快照；401/403/404、认证/协议错误清除结果。节点不可用、快照失效或范围变化会清已选位置。
- 游标追加不改变范围 key，保留累计页与拓扑 revision；实际失效游标清累计，重试从首批恢复。排序选择器也支持第二批锚点，不提交未加载的全体兄弟节点。
