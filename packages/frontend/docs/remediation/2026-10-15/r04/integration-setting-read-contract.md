# R04-F 集成与系统设置读契约交接

日期：2026-10-19。本文描述前端消费投影，**不是已经批准或实现的 HTTP 契约**。本轮限定前端；未新增后端、Prisma、权限或配置写入。

## 所有权与边界

| 内容 | 所有者 | 前端边界 |
| --- | --- | --- |
| 可见集成目录、独立详情、集成事件与同步记录 | `module/integration` | 可选只读来源；每项明确部署级或组织级归属 |
| 归档保留、审计导出范围、邀请期限、默认时区 | `module/organization` 的独立 policy 来源 | 组织规则或继承部署默认值的明确事实；不从根环境配置推导 |
| 可公开版本、构建时间与环境名称 | `module/deployment` | 经授权的白名单摘要，不是部署配置浏览器 |
| 账户与个人偏好 | 现有账户设置 | 只保留导航，不另建状态或表单 |

三类新来源均不在生产装配。没有来源显示暂不可用，不加载 fixture、不猜测接口、不用 liveness/readiness 代替集成健康。现有 Storage/IAM/Mail 单例及服务器内部配置不构成组织管理员的读取或修改授权。

## 集成读取

`IntegrationDataSource` 提供 `list`、`detail`、`logs`，均接受取消信号。

- `list(organizationId)` 返回此账户在该组织可见的完整小规模目录及测量时间；列表条数仅表示可见条目，不声称组织总数。类别来自来源，文件存储/身份/网关/Webhook 不自动成为四条已配置记录；未知类别保留名称和标识。
- `detail(organizationId, integrationId)` 独立读取，不把目录摘要当作完整配置。返回身份、归属、连接状态、探测/同步/创建时间、创建人、说明、可空配置摘要和可空事件目录。
- 连接状态分别表示已连接、连接异常、未配置、未探测、未知。连接不代表同步完成，认证材料已配置不代表凭据有效。
- 配置摘要仅有服务提供方名称、认证材料是否已配置、是否启用传输加密及摘要可用性/原因。没有端点、用户名、密钥、密文、存储桶、区域、文件路径或任意 key/value 配置容器。没有凭据占位字符串或解密入口。
- 事件目录由来源给出，保留未知 code；`null` 为未提供，空数组为已知无事件，启用为 `boolean | null`，不把缺失值当作关闭。
- `logs` 使用明确的当前集成、`activity`/`sync` 类型、每批 50 条和不透明游标；响应回显组织、集成、类型与当前游标。记录只含时间、白名单事件名称、结果与已净化说明，不接收原始请求、供应商异常、堆栈或 payload。
- 没有总量与随机页码，不对当前一批执行冒充全量的本地搜索/排序。换组织、集成、顶层视图或详情视图清除游标；深链允许独立读取所选集成，目录失败且没有保留快照时关闭下级读取。

## 组织治理读取

`OrganizationPolicyDataSource.read(organizationId)` 独立于组织资料/统计读来源，不改变原接口。四项规则均有来源标记（组织、继承部署默认值、未知）及由来源提供的作用/影响说明。

保留期与邀请期限是来源的正整数天数或未定义；前端不推断自动归档、删除、永久保留或硬编码七天。审计导出范围只解释规则，不计算账户有效权限、角色继承或实际导出能力。时区必须是合法 IANA 名称或未定义；展示不会修改事件原始时间、浏览器时区或调度器。

尚需后端确认保留期确切语义、单位与永久规则、缩短影响，导出权限/角色生命周期，邀请期限所有权，以及时区对显示/调度的作用。没有保存、取消、重置、测试、同步或组织生命周期命令。

## 部署安全信息读取

`DeploymentInformationDataSource.read(organizationId)` 返回经该账户在此管理上下文获准查看的部署安全摘要。`organizationId` 用于访问范围校验，不表示部署归组织所有。字段仅限 `version`、`builtAt`、`environmentLabel`、测量时间和组织范围，均允许明确缺失。

不得投影 `.env`、环境变量枚举、连接 URL、主机/服务器路径、许可证、云凭据、IAM/SMTP 参数、存储连接信息或任意内部配置。前端不从本地 package 版本伪造服务端版本，不从开发服务器状态推断部署环境，不虚构订阅/配额。

## 安全失效与恢复

页面的组织选择仅修改本页 URL，不切换全局工作区。账户、组织、集成、查询与消费上下文变化同步清旧结果并取消读请求；忽略取消的迟到响应不得发布。卸载取消读取。

响应使用结构化 schema，投影只保留声明字段，校验身份、日期、唯一标识、日志类型与游标。401、AuthenticationError、403、404、投影无效清旧结果；同上下文临时故障可保留有明确过期提示的上次结果，恢复操作只重读。白名单字符串本身必须由未来服务端适配器净化，前端 schema 不能证明任意文本不含秘密。

## 真实接线前必须确定

1. 部署管理员与组织管理员的授权模型；哪些部署摘要确实允许公开。
2. 集成注册、可见目录、独立详情和按集成隔离的活动/同步读接口及游标语义。
3. 配置、健康检查、同步、密钥重置各自的权限和幂等/不确定结果语义；本轮不启用命令。
4. 组织治理规则存储、继承、修订冲突和写后只重读；不能由页面独立修改运行环境或邀请规则。
5. 真实账户/组织隔离、撤权、敏感字段负向验收和服务端内容净化。

读投影与隔离验收完成不等于集成同步引擎、设置保存、部署管理或整个 R04 完成。
