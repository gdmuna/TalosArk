## 行为验收

一次性隔离浏览器及响应投影检查共 **73 项通过**，页面运行错误为 0；结构化结果见证据目录 `verification.json`。临时入口已删除，没有新增生产来源或长期测试脚本。一次“点击当前标签应规范化 URL”的探针预期已纠正：当前标签的 model 不发生变化，不触发 setter，仍保持既有无导航行为；该探针调整独立记录在 `attempts`，不作为产品通过项计数。

- 集成配置只展示白名单摘要，事件未知 code 保留；未提供事件目录与已知无事件明确区分。未知类别包括 `toString` 能安全回退图标。
- 活动日志与同步记录按组织、集成、类型和游标分别读取；下一批/返回首批有效，不显示假总数、随机页码或批次内冒充全量的搜索排序。
- 真实视图切换推入历史并原子清游标，返回恢复原视图/游标；返回默认视图省略 query，重复选择不导航，无关 query/hash 保留。
- 组织选择通过现有 SelectField 操作，只改变本页上下文，不激活全局工作区；账户清空、组织/集成切换同步清旧结果。来源即使忽略 AbortSignal，也不能用迟到响应覆盖新上下文。
- 集成目录/详情的 401/403/404、AuthenticationError、错误组织/身份、重复目录、损坏日期与日志范围/游标错误清除旧数据。目录失效且无旧快照时卸载下级详情。
- 同范围集成目录/详情临时 503 保留带明确过期提示的旧快照，重试恢复且仅重读。未开放保存、测试连接、同步或凭据修改命令。
- 组织规则与部署信息各自的认证/授权/协议失败不会伪装成功，也不会清除另一来源的正常结果；缺失值不推断为 7 天、365 天、默认时区或本地应用版本。
- 无来源时调用数为 0；离开路由及销毁应用取消读请求。独立集成深链不依赖目录摘要填充详情。
- schema 移除未声明的原始 payload/配置密码字段；类型、超量日志与重复游标被拒绝。页面不显示注入的秘密或内部错误哨兵。未来适配器仍须保证白名单字符串已净化，前端 schema 不是服务端脱敏证明。
- 刷新图标按钮使用正确的 `use-tooltip` 开关，具备可访问名称。
