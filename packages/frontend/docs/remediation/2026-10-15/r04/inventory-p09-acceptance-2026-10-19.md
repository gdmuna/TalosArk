## 本轮接通

| 入口 | 能力 |
| --- | --- |
| 材料创建/编辑 | 数量精度 0–6，默认 6；编辑保留原值，已有实例时冻结单位、分支和精度 |
| 材料详情 → 来源批次 | 服务端搜索/状态/分页，独立预览和详情，新建/编辑/归档/恢复，按真实 canManage 开放 |
| 批次详情 | 按材料 ID 与批次 ID 独立读取；可跳至该批次的库存列表 |
| 库存列表 | 实例、材料、批次、数量、状态、有效期风险、可见位置、入库时间；服务端搜索/分页 |
| 库存预览/详情 | 预览按 ID 独立读取；详情显示实例日期、数量、批次、当前位置及流水，并保留来源快速返回与视图 URL |
| 登记入库 | 一次登记一件实物；选择材料、可选批次与可用空位置；输入数量、编号、最终日期和实物资料 |
| 实例资料更正 | 按 capability 开放；提交完整事实、expectedRevision、原因和过期确认；不开放数量、位置、编号、材料或批次归属修改 |
| 库存概览 | 真实实例总量、业务日期、权限和最近入库；不伪造趋势、出库统计或“预警为零” |
| 出入库流水 | 服务端搜索实例编号与分页，支持 stockItemId/operationId 范围；独立详情展示全部明细及历史位置快照 |
| 旧组织权限配置 | 概览为服务端确认的组织所有者提供显式确认入口，将库存和批次权限补入工作区管理员预置角色；读取页面不会自动执行此命令 |

库存与流水契约没有自定义排序参数，相关列不提供无效排序控件。批次只提供契约已有的搜索、状态和分页。CURRENT 展示“有效”，不冒充“临期”。位置不可见时展示“位置受限”，不解释为未分配。

来源批次是材料的厂家/来源批号，不是 Cell Bank；保留的旧 Bank 路由不伪造专业培养模型。

跨材料、设施和团队的入库/权限配置表单放在 `page/inventory/component` 组合，库存模块不直接依赖材料或设施实现。库存读取与既有材料模块一样，通过工作区公开入口获得当前上下文；已同步声明这项依赖并保留其余架构限制。

## 输入与恢复行为

- 数量始终按字符串传递，不转换为浮点数；允许零，检查材料精度，零量库存仍占位置。
- 未知、无期限与指定日期分别表达。生产日和有效期使用日历日期；过期比较采用服务端业务日期，不采用浏览器 UTC 日界线。
- 选择已有批次时读取独立详情与修订号，复制日期作为本件实物的默认值。搜索或翻页不会丢失当前材料/批次及其修订号。
- 材料、批次可搜索并翻页；位置采用有界游标翻页。候选不是位置预留，最终由后端重查授权、可用性和占用。
- 库存、批次和流水翻页期间保留已知总数，不因暂时清空当前页记录而将页码钳回第一页；查询、范围变化及失败按各自上下文重置。
- 打开入库/更正表单时重新读取权限和业务日期；收到过期确认错误时刷新业务上下文，允许用户重新确认。
- 入库第一次明确失败可以修改后重提；网络、超时、协议或服务端异常后锁定原请求与幂等键，重试沿用相同 scope/body/key。已有不确定结果时，后续冲突或撤权不会把请求静默变为新请求。
- 不确定入库请求由库存模块持有，并按账户保存在当前标签页 sessionStorage；路由往返与同标签页刷新保留原 scope/body/key，退出或切换账户清理。关闭标签页、跨窗口/跨浏览器不承诺恢复。
- 已确认写入与写后重读分别处理。重读失败显示已成功但未同步，恢复入口只读取，不能重新执行入库或资料更正。
- 普通批次读取失败不会显示“操作已成功”；确认写入后的同步失败才使用这条提示。
- 更正资料发生冲突或结果不确定时阻止直接重提，要求重新读取最新资料。已保存但同步失败时只重读详情。
- 切换账户/工作区/记录或卸载视图时取消局部读取、清除选择并忽略迟到结果。入库写入由模块持有原范围，离开页面不会换键或改写为新范围；会话暂不可用时暂停并保留恢复信息，明确退出/切换账户才清理。读响应检查 Zod 结构、组织/工作区/实体身份及分页；认证、权限、消失或协议错误清除敏感快照。
