# B 组：材料

共 11 张稿。材料定义、Bank、Batch、物理库存实例、培养记录不是同一个对象；排版不能用一个通用空表格抹平差异。谱系、培养、QC 的首发范围仍需对应业务切片确认。

2026-10-20 R05：B-01/02/04/05 已按当前契约整改构图、即时预览、批次上下文与关联库存分页，并补摘要导航、入库预填和录入校验 / 草稿关闭保护，见 [实施](r05/README.md)、[验收](r05/acceptance-2026-10-20.md)。下述“当前差异”为原整改基线；培养 / QC / 谱系、预留量和专业 Bank 事实仍需正式来源。

## B-01 材料概览

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-01.png) · `/main/material/overview` · [源码](../../../src/page/material/Overview.vue)

- **图中构图**：顶部摘要；最近材料变化占左侧，分类分布在右；下方待检验清单与常用动作形成主辅关系。
- **当前差异**：已有这些标题，但多处指标未知、数据区未接入；标题齐全不等于形成有效看板。

- **验收**：加载和局部失败独立；有权看概览但无创建权限时仍可浏览，不展示假趋势或把未知当零。

## B-02 全部材料与 Inspector

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-02.png) · `/main/material/list` · [源码](../../../src/page/material/List.vue)

- **图中信息**：名称/标识、分类、状态，以及库存/实例/QC/位置等摘要；选中后能理解材料与其库存的关系。
- **当前差异**：已有分支筛选、DataTable 与 Sheet，但条目仍依赖 workbench 资源读模型，未证实材料完整契约；不能把泛资源数量列当库存事实。
- **目标**：名称+型号/目录号作为第一列；生物材料/试剂/耗材按当前领域分类，不强行照抄图中分类；类别 badge 与状态 badge 区分。明确可用数量及单位、实例数、检验状态、更新时间的含义。
- **交互**：整 cell 预览，Sheet 只放核心事实、关联实例摘要、进入完整详情与权限允许的动作；不在窄 Sheet 再塞 7 个 Tab。筛选应影响全查询，不仅本页。
- **依赖**：P07 真实材料读写与授权、P09 的库存聚合；没有对应量时只不展示该量，不制造 0。
- **验收**：三类材料的差异字段、长名称、无图片、零库存/未知库存、权限拒绝、创建回列表均能辨认；选中不等于批量勾选。

## B-03 培养物列表与 Inspector

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-03.png) · 当前无独立列表入口 · 建议 `/main/material/culture`，需在业务范围确认后新增。

- **图中信息**：培养物编号、关联材料、代次、状态、位置、更新时间；预览显示来源、关联实例及培养历史，提供换液等记录动作。
- **当前差异**：材料导航只有概览/列表，不能把材料定义列表重命名成培养物列表完成此稿。
- **目标**：保留同级导航但不增加永久侧栏；表格主列培养物编号+材料名，代次/培养状态/操作时间分列，选择培养物后 Sheet 呈现上下文。
- **交互**：培养操作属于记录/事件命令，非直接编辑当前状态字符串；能进入 B-06 的对应材料与记录，失败保留表单。
- **依赖**：阶段保留，培养对象与事件契约尚未纳入已完成 P07；权限/代次规则不能由前端发明。
- **验收**：材料定义、物理实例、培养物三种 ID 不混用，历史只跟随当前选择，非培养材料没有无效入口。

## B-04 材料详情·概览

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-04.png) · `/main/material/detail/:resourceId?view=overview` · [源码](../../../src/page/material/detail/Detail.vue)

- **图中构图**：完整对象头+7 个本地标签；主栏基本属性与批次摘要，辅栏库存/实例统计、近期活动和关联入口。不是 5 个空区块纵向堆放。
- **当前差异**：已有对象头/标签，但 `ResourceDetailPage` 的 `w-fit` 及大量空表格破坏稳定构图；泛资源字段不足以填详情。
- **目标**：1280px 画布，头部与正文对齐；主辅约 2:1；基本字段分组为身份、来源/供应、规格与保存条件，具体字段按材料类型契约；摘要链接到实例、Bank、检验、文件。
- **交互**：对象头保留 ID 复制、状态、所属区与主要命令；返回列表恢复条件；7 个 view 中培养/谱系只对支持的材料出现，不做死链接。
- **依赖**：P07 详情读模型、P09/P10 的关联摘要，培养/QC 另定；不可读与不存在遵循 API 的安全口径。
- **验收**：深链刷新可还原对象与 Tab；两种材料类型、长字段、部分摘要失败、小宽度单列均保持内容层级。

## B-05 材料详情·实例与库存

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-05.png) · 同材料详情 `?view=instance`

- **图中构图**：批次选择与选中批次概况在上，下面为物理实例表；选中实例展示位置/状态/数量，能跳库存详情。
- **当前差异**：现有是空实例表，缺批次上下文和可用/占用/已使用等数量口径。
- **目标**：批次摘要为稳定横排事实，不套额外卡片；表列实例 ID、所属 Batch、位置全路径、状态、数量/单位、入库时间；选中详情用 Sheet。
- **交互**：切批次更新查询与选择；入库进入 G-07 带材料/批次；有库存身份的行去 C-09，Bank/Batch 去 B-11，不统一去材料列表。
- **依赖**：P09，Batch/Bank 接口需按实际模型确认；不能把材料全部关联对象当物理库存。
- **验收**：跨批次过滤、未知位置、无可用库存、已预留数量、单位正确；摘要与分页计数各自明确。

## B-06 材料详情·培养

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-06.png) · 同材料详情 `?view=culture`

- **图中构图**：上方培养物列表，下方**当前选中培养物**的历史；历史包含时间、操作、人、代次/状态与备注。
- **当前差异**：现有空表不足以说明选中关系，容易成为两个无关表格。
- **目标**：列表选择和历史标题绑定；初始明确“选择培养物”，有数据时可恢复指定 cultureId；历史用紧凑时间线或表，不硬铺过高空白。
- **交互**：新培养/换液/传代分别独立命令表单，确认原对象/来源，提交后刷新相关对象与谱系；历史不可任意覆盖。
- **依赖**：与 B-03 同阶段；图里的操作名称不能直接当批准的后端能力。
- **验收**：切换行中旧请求晚到不改新历史；记录失败可恢复；非培养材料直接隐藏该 view 并处理旧深链。

## B-07 材料详情·谱系

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-07.png) · 同材料详情 `?view=lineage`

- **图中构图**：宽画布呈材料→批次→实例→培养节点及关联线；右侧为选中节点属性，顶部筛选/缩放/适配。
- **当前差异**：固定 420px 空白画布和禁用缩放没有表达关系，不能算谱系视图。
- **目标**：横向工具工作区，画布利用剩余高度且可缩放/平移；节点显示种类、名称、关键状态，选中清晰；右侧局部属性面板是画布工具的一部分，不恢复全站旧 Inspector。
- **交互**：沿用现有 Vue Flow/Dagre；缩放有边界，fit 只在初始/明确点击，不在每次刷新跳回；节点可进入实体详情，连线有方向和关系含义。
- **依赖**：阶段保留，关系查询、环/断链语义和授权剪裁待定义；不从名称猜亲缘。
- **验收**：单节点、长链、多分支、部分不可见、孤立节点与大量节点均非空白/互相遮盖；键盘有列表替代入口。

## B-08 材料详情·QC

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-08.png) · 同材料详情 `?view=quality`

- **图中构图**：检验记录列表与选中记录详情，呈检验类型、对象批次、日期、结果、负责人、报告/附件和审核信息。
- **当前差异**：列表加空详情仅完成占位；结果与审核状态没有真实来源。
- **目标**：主列表+有选中关系的详情，明确“检验结果”和“审核状态”两种状态；统一中文“检验/QC”命名，不在页面间随机换名。
- **交互**：上传报告→绑定目标→结果登记/审核（如获批准）分别表达；报告预览按文件权限，不用一个下载 URL 当永久公开链接。
- **依赖**：P10 附件，质量记录/审核超出已完成阶段需单独确认。
- **验收**：待检、通过、不通过、撤销/无效、无报告分别可辨，不同批次检验不混入材料全局结论。

## B-09 材料详情·文件

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-09.png) · 同材料详情 `?view=file` · [共享呈现](../../../src/page/resource/ResourceFile.vue)

- **图中构图**：文件名/类型/版本/大小/上传人/更新时间清单，与实际预览区；上传与关联已有文件是不同动作。
- **当前差异**：ResourceFile 永远是空列表和禁用按钮，无选中文件/预览逻辑。
- **目标**：列表占主要宽度，选中后可用 Sheet 或专用预览区；文件类型图标、大小和上传状态可扫读，预览不可用时给下载而非假封面。
- **交互**：G-06 完成上传/绑定；解绑与删除物理文件分开，版本能力只在契约支持时显示，失败上传可单项移除/重试。
- **依赖**：P10，沿用绑定型文件模块，不建设独立网盘/任意历史版本系统。
- **验收**：PDF/图片/不支持格式、上传中、上传成功绑定失败、授权过期、解绑后旧链接均正确。

## B-10 材料详情·活动

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-10.png) · 同材料详情 `?view=activity`

- **图中构图**：按时间分组的事件时间线，含操作者、动作、对象、变更摘要，可展开前后值/关联记录。
- **当前差异**：空活动表不能保留事件叙事；不应硬把所有内容压成一条字符串。
- **目标**：时间分组+细时间、头像/动作图标、摘要正文、对象链接；人员/类型/日期筛选紧凑；敏感字段不回显。
- **交互**：审批/流水/文件事件分别进入来源；已知图稿的复数目标位置错误不复制，库存转移显示明确单一 from→to。
- **依赖**：审计/业务事件关联读模型，随 P07-P11 事件逐步接入，不把审计原始 JSON 当用户时间线。
- **验收**：空事件、分页追加、同刻多个事件、操作者已离开组织都可读，历史不因当前成员删除而消失。

## B-11 Cell Bank 与 Batch 专业视图

[设计稿](../../../../../output/design/frozen-v2-71-2026-09-29/B-11.png) · [Bank](../../../src/page/material/detail/Bank.vue) 与 [Batch](../../../src/page/material/detail/Batch.vue)

- **当前路由**：`/main/material/detail/:resourceId/bank/:bankId`（overview/batch/quality/file）；其下 `/batch/:batchId` 为独立 Batch 详情。
- **图中构图**：Bank 对象头、状态与 4 个本地标签；批次数/冻存量/放行量/实例摘要；批次列表与选中批次摘要形成关联。
- **当前差异**：已有文件与标签骨架，但 Bank/Batch 都主要核查父材料，不能据此证明 bankId/batchId 对象存在或属于该父对象。
- **目标**：Bank 页面保留细胞库身份和层级面包屑；Batch 页面有自己的名称/编号/状态、生产/入库/检验信息、关联实例，不把两页做成材料通用详情复制品。各 view 分别为身份事实、批次表、检验、文件；Batch 的实例与检验也必须有数据来源。
- **交互**：批次选择可预览，再进入完整 Batch；材料→Bank→Batch→实例连续可回退；不存在或不属于父对象时不显示父材料的“正常”假详情。
- **依赖**：专业模型是否首发需业务确认；即使已有 Prisma 模型也不等于有读模型/授权/工作流。
- **验收**：直接访问有效/错误 bankId/batchId、换父 ID、刷新深链、权限撤销全部正确；冻存管数、容量与可用数不能混算。
