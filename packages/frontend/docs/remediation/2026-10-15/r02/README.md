## 请求与恢复

- 服务端返回的成功快照决定可见页码、页容量及查询上下文；`appliedSearch` 仅在对应读取成功时更新。
- 搜索或页容量请求失败后，旧数据保留且显示错误。下一次翻页恢复可见快照的查询；“重新加载”才显式重试失败请求。切换组织/成员范围清空旧搜索并回到第一页。
- 删除末页唯一记录后，读取有效末页，不显示空白的越界页。
- 已确认写入、随后同步失败时，保留 DataSyncNotice，暂停团队后续写入，恢复按钮只重读，不重放命令。表单内也可恢复。
- 切换范围保留既有取消/代次隔离；旧响应忽略取消后晚到也不能覆盖新范围。401/403 清除不应继续展示的旧数据，并关闭失效预览/表单。
