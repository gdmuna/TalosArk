## 浏览器清单

| 场景             | 核对内容                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 启动恢复         | 会话服务断网保留 URL 和 startup；重试成功回原 path/query/hash                                          |
| 账户读取失败     | 从账户阶段重试，不重复成功的会话恢复                                                                   |
| 密码登录         | 错误密码、显隐、经找回返回后 next 保留、成功回原页                                                     |
| SSO 成功         | 模拟外部跳转/回调，清除 code/state，消费返回状态并回原页                                               |
| SSO 故障         | 发起失败可重试；缺 state 回调显示结果和返回登录                                                        |
| 回调响应校验失败 | 无协议错误文本，有重新登录入口                                                                         |
| 找回密码         | 通用受理口径、服务端冷却时间、429 状态                                                                 |
| 重设校验         | 密码不一致无请求、焦点落在确认输入、成功仅提交一次                                                     |
| 无效一次性链接   | 重设/激活无效响应卸载表单；刷新无 token 不再提交                                                       |
| 激活成功         | 结果明确，不自动执行密码登录                                                                           |
| 防重复登录       | 账户请求期间禁用提交和企业 SSO，避免同时发起                                                           |
| 策略拒绝         | 保留密码草稿供修正，显式再次提交                                                                       |
| 首设已有密码     | 拒绝后去除表单，提供找回密码                                                                           |
| 首设认证过旧     | 保留具体说明，提供重新认证                                                                             |
| 邀请登录往返     | 匿名只登录，SPA 登录后恢复预览，不自动接受                                                             |
| 邀请恢复失败     | 显式重试恢复预览，无空白死路                                                                           |
| 邀请写后同步失败 | 成功态保持，恢复仅重读；accept 请求次数始终为 1                                                        |
| 邀请刷新         | hash 已清除，浏览器存储不保存邀请 token，刷新不自动接受                                                |
| 邀请账户不匹配   | 统一服务端口径，切换账户后 next 为邀请页                                                               |
| 空目录           | 无组织/组织无区的标题与动作不同；创建 Dialog 的 Esc 与焦点返回                                         |
| 断网退出         | 本地退出、服务器撤销未确认反馈、刷新/受保护入口不自动恢复                                              |
| 启动主动返回登录 | 用户显式选择，保留 next                                                                                |
| 响应式           | 1440×900、390×844、390×600、320×568；登录/找回/重设/激活/邀请/回调的标签关联、无横向溢出、底部动作可达 |
