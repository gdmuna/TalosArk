# R08-B 全局入口验收

日期：2026-10-23，Asia/Taipei。沿用 R08-A 的未提交改动，仅新增本包前端实现和记录；没有修改后端、公开契约、依赖或业务权限。真实组织保持只读，全部写入及故障恢复在隔离浏览器验证。

## 验收

20 个 Microsoft Edge / Playwright 隔离场景通过：

1. 只读账户事实与个人通知延期状态。
2. 未保存草稿切换视图、继续编辑与放弃。
3. 账户写入成功后同步故障只重读，写入次数保持 1。
4. 相同显示名的账户切换也清除旧草稿。
5. 空组织显示与搜索空状态区分。
6. 切换器键盘选择和焦点返回。
7. 临时切换失败保留旧选择并可恢复。
8. 撤权移除过期候选。
9. 关闭重开后的晚到成功不关闭新面板。
10. 多次展开/收起保持锚定，文字 tooltip 不阻塞相邻按钮。
11. 用户菜单→切换器→创建 Dialog→触发点的焦点交接，未提交创建。
12. 应用设置保留原账户入口，偏好即时持久化，活跃模态中快捷键不打开另一层命令面板。
13. 帮助/关于共用浮层、真实版本、Tab 焦点限制及关闭重开分类保持。
14. 未登录的 390px 窗口可打开设置，不发起会话恢复，浮层不超出视口。
15. 命令面板范围说明、过滤、重开清空及中文 IME Enter。
16. Home/End 与连续方向键结束后的目标完整可见；保留平滑滚动及重复键即时策略。
17. 资源结果元信息及文件不跳设备；有所属材料时打开文件子视图。
18. 未知页不启动读取，不回显 query；内部 404 返回保留原视图 query。
19. 长组织/工作区名称与 20 个候选在 1024×640 视口内可搜索、可滚动、不横向溢出。
20. 无组织切换器提供明确空态，只启用当前支持的创建动作。

全部 HTTP 请求由浏览器截获并以公开 schema 的合成数据响应；账户可编辑与资源投影场景显式注入浏览器内的临时适配器/投影，未写真实组织。无未捕获页面异常。

R08-A 的 23 个浏览器场景同时回归通过。类型检查、修改源码 ESLint、Prettier、生产构建和 git diff --check 通过；构建保留原有静态路由整体包大小提示。

## 保留边界

- 生产账户来源仍为只读；新增页面不会凭空获得昵称修改接口。
- 全量资源搜索、权限化检索与设备巡检没有正式来源，未补造接口或生产命令；保留已有显式来源下的展示和命令边界。
- 通知中心与个人通知偏好待 P16；深色主题继续暂缓。
- 真实多组织/权限矩阵、原生 125% 缩放、Tauri 窗口能力及外部文档站部署未验收；项目文档入口指向仓库，不宣称已有在线用户手册。
- R08-C 的全业务 Sheet/Dialog、表格控件与 P13 浮层回归尚未执行。本包仅验证涉及的全局入口，不能算整个 R08 完成。
