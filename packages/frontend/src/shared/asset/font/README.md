# Source Han Sans

Adobe Source Han Sans 2.005R, Simplified Chinese regional subset,
variable TrueType WOFF2 (weight axis 250-900).

- File: `source-han-sans-cn-variable.woff2`
- Source: https://github.com/adobe-fonts/source-han-sans/blob/release/Variable/WOFF2/TTF/Subset/SourceHanSansCN-VF.ttf.woff2
- License: SIL Open Font License 1.1, included in `LICENSE.txt`.

The font covers Chinese and Latin text. `font-display: swap` keeps text visible
while it loads; the bundled file supports offline desktop use. The regional
subset also covers user-entered Chinese beyond fixed application strings.
