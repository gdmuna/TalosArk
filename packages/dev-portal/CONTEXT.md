# Dev Portal

Dev Portal 是 TalosArk 的开发者仓库工作台。它将开发资源及其状态关联起来，帮助开发者了解功能进展、定位依据并浏览真实定义。

## Language

**功能（Feature）**：
有明确交付目标的一项产品能力，是需求、Issue、设计和实现资源的共同关联对象。
_Avoid_: 用目录、提交或单个文件代替功能。

**Issue**：
仓库中记录具体工作及其生命周期的一项任务。一个功能可以包含多个 Issue。
_Avoid_: 将 Issue 状态当作功能各层的实现程度。

**资源（Resource）**：
看板能够定位、浏览和关联的开发对象，包括功能、Issue、文档、包、代码模块、文件、设计资产、数据库定义和接口定义。
_Avoid_: 与业务系统中的样本、库存或 ResourceIdentity 混用。

**代码模块（Code Module）**：
在所属包中有明确职责和可识别入口的代码所有者，其范围由仓库约定或显式声明确定。
_Avoid_: 将每个目录都视为一个代码模块。

**设计资产（Design Asset）**：
前端设计基础、真实 UI 组件或有明确出处的交互示例。设计资产描述实际定义及其可用预览。
_Avoid_: 将独立重绘的组件效果当成真实组件预览。

**数据库定义（Database Definition）**：
仓库对数据模型、枚举、关系和原生数据库对象的声明。
_Avoid_: 将仓库定义当作实际数据库已经部署的结构。

**接口定义（API Definition）**：
业务接口的公开操作说明或 wire schema。契约存在与接口已实现是两个不同事实。
_Avoid_: 把内部 Core 接口、Prisma 类型或看板自身接口混入业务公开契约。

**资源关联（Resource Link）**：
两个开发资源之间有依据的关系，例如某文档说明某功能，或某模型属于某功能。
_Avoid_: 用名称相似或目录邻近推断已确认的关系。

**实现程度（Implementation Maturity）**：
功能某一交付维度的能力程度，区分定义、mock、实现和验证。
_Avoid_: 以代码量、文件数量或提交数量推算完成度。

**验证证据（Verification Evidence）**：
一次检查的可追溯结果，包含检查对象、对应版本、时间和结果。
_Avoid_: 无来源的通过标记，或将旧版本结果作为当前版本验证。

**来源快照（Source Snapshot）**：
一次索引发布所对应的仓库来源集合及版本记录，包括工作区未提交内容。
_Avoid_: 仅用 Git HEAD 代表完整工作区状态。

**来源诊断（Source Diagnostic）**：
对某个数据源读取、解析、关联或刷新状态的说明。
_Avoid_: 把来源异常当作被追踪功能的业务失败。
