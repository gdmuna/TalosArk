面向 TalosArk 开发者的仓库工作台，集中浏览项目进度、文档、代码结构、前端设计系统、数据库定义和接口契约，并通过搜索与资源关联串联这些信息。

> 状态：设计基线 v0.1，2026-10-10。当前目录仅包含设计文档，尚无应用代码、启动命令或已接入的数据源；未注册为 pnpm workspace 包。

## 设计基线

- 单仓库、本地开发优先；首版只读浏览，允许搜索、筛选和刷新索引。
- 前端沿用 Vue 3、TypeScript、Vite、Tailwind CSS、shadcn-vue / Reka UI 和 Vue Router，按实际需要使用 Pinia、TanStack Vue Table、Vue Flow 与 Dagre。
- 建议使用 Elysia + Node 提供本地仓库读取与索引能力，继续使用 pnpm。这个选型包含学习 Elysia 的目标，实施时选用兼容的稳定版本；尚未安装依赖或验证运行行为。
- 看板独立于业务应用运行；使用看板不要求启动 NestJS 后端或连接业务数据库，实时 API 文档和组件预览按可用性接入。
- 看板自身的数据协议留在本包，既有业务 wire schema 继续归 `@talos-ark/contracts` 所有。

## 范围

首版提供概览、项目进度、文档、项目结构、设计系统、数据库 Schema、API 与契约七个主入口，以及全局搜索和数据源状态入口。

后续阶段增加变更关联、质量状态和开发环境导航。首版不提供任务写入、代码编辑、数据库写入、任意命令执行、登录与团队权限、多仓库管理或插件平台。

实施前应把本目录加入 workspace 并补充实际脚本；这些工作不属于本次文档交付。
