# Dev Portal 导航与路由矩阵

> 状态：设计基线 v0.1，2026-10-10。路由均为待实现设计，当前仓库尚未注册这些页面。

本文拥有路由路径、名称、页内视图和 URL 状态规则。页面业务规则见 [业务设计](./business-design.md)，资源参数规则见 [资源设计](./resource-source-design.md)。

## 1. 导航层级

```text
Dev Portal
├─ 全局搜索 / 快速定位
├─ 项目
│  ├─ 概览
│  └─ 项目进度
├─ 开发资源
│  ├─ 文档
│  ├─ 项目结构
│  ├─ 设计系统
│  ├─ 数据库 Schema
│  └─ API 与契约
└─ 底部状态入口
   └─ 数据源状态
```

分组标题不产生路由。仓库名称、分支、工作区修改提示和索引状态出现在全局上下文栏；首版没有项目切换器、用户菜单或登录入口。

| 开发资源 | 设计系统      | `/design`    | `/design` 及其子路径    | 重定向到设计基础             | P0   |
| 开发资源 | 数据库 Schema | `/schema`    | `/schema` 及其子路径    | ER 图及模型目录              | P0   |

## 3. 路由矩阵

下表包含首版路由。`view` 是同一资源的持久页内视图，用 query 表达；资源身份变化使用 path 参数。默认 query 值在 URL 中省略。

### 项目与进度

| 路由名称                | 路径                           | 页面职责                         | 页内视图 / 默认值                                    | 详情与返回关系                                                |
| ----------------------- | ------------------------------ | -------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------- |
| `portal-root`           | `/`                            | 进入看板                         | 重定向 `/overview`                                   | 使用 replace，不额外留下首页历史                              |
| `portal-overview`       | `/overview`                    | 项目概览                         | 无                                                   | 摘要链接指向相应筛选列表                                      |
| `portal-progress`       | `/progress`                    | 功能工作集合                     | `view=matrix`；可选 `board`、`list`                  | 打开功能或 Issue 详情                                         |
| `portal-feature-detail` | `/progress/feature/:featureId` | 功能详情与交付依据               | `view=summary`；可选 `matrix`、`issues`、`resources` | 面包屑到项目进度；关联资源进入各自路由                        |
| `portal-issue-detail`   | `/progress/issue/:issueId`     | Issue 原始状态、依赖、说明和来源 | 无                                                   | 已确认所属功能时，面包屑包含功能；来源链接进入文档 / 文件详情 |

### 文档与结构

| 路由名称                 | 路径                            | 页面职责                         | 页内视图 / 默认值                               | 详情与返回关系                             |
| ------------------------ | ------------------------------- | -------------------------------- | ----------------------------------------------- | ------------------------------------------ |
| `portal-document-list`   | `/docs`                         | 文档分类、目录和检索             | 无                                              | 打开文档详情                               |
| `portal-document-detail` | `/docs/:docId`                  | 文档正文、目录、出处和关联       | `view=preview`；可选 `source`                   | 支持标题锚点；来源位置可跳到文件详情       |
| `portal-structure`       | `/structure`                    | 文件与代码职责导航               | `view=tree`；可选 `package-graph`、`module-map` | 图与列表定位包、模块或文件                 |
| `portal-package-detail`  | `/structure/package/:packageId` | 包职责、依赖、脚本说明与资源     | `view=summary`；可选 `dependency`、`resource`   | 面包屑到项目结构                           |
| `portal-module-detail`   | `/structure/module/:moduleId`   | 已确认模块的职责、入口与直接依赖 | `view=summary`；可选 `dependency`、`source`     | 所属包存在时面包屑包含包                   |
| `portal-file-detail`     | `/structure/file/:nodeId`       | 文件源码、行定位与关联资源       | 无                                              | 根据源路径展示面包屑；支持返回树并聚焦文件 |

### 设计系统

| 路由名称                         | 路径                             | 页面职责                 | 页内视图 / 默认值                                     | 详情与返回关系                       |
| -------------------------------- | -------------------------------- | ------------------------ | ----------------------------------------------------- | ------------------------------------ |
| `portal-design`                  | `/design`                        | 设计入口                 | 重定向 `/design/foundation`                           | 保留明确支持的 query，不透传无关参数 |
| `portal-design-foundation`       | `/design/foundation`             | 设计基础和 token         | `view=token`；可选 `typography`、`geometry`、`motion` | 可定位 token，关联规范与 CSS 来源    |
| `portal-design-component-list`   | `/design/component`              | 已收录组件目录           | 无                                                    | 打开真实组件详情                     |
| `portal-design-component-detail` | `/design/component/:componentId` | 组件定义、示例与真实效果 | `view=preview`；可选 `props`、`usage`、`source`       | `example` 选择已有示例；返回组件目录 |

设计基础与组件目录是页面内二级导航，不新增一级侧栏项。不存在独立主题配置页、业务页面预览目录或无限制组件沙箱。

### 数据库与 API

| 路由名称                      | 路径                          | 页面职责                    | 页内视图 / 默认值                                     | 详情与返回关系                |
| ----------------------------- | ----------------------------- | --------------------------- | ----------------------------------------------------- | ----------------------------- |
| `portal-schema`               | `/schema`                     | 数据库定义集合              | `view=erd`；可选 `model`、`ddl`                       | 模型、枚举与 DDL 进入各自详情 |
| `portal-schema-model-detail`  | `/schema/model/:modelId`      | 模型字段、关系与约束        | `view=field`；可选 `relation`、`constraint`、`source` | 返回 ER 图时可聚焦本模型      |
| `portal-schema-enum-detail`   | `/schema/enum/:enumId`        | 枚举项、引用与源码          | 无                                                    | 跳转引用模型或源码            |
| `portal-schema-ddl-detail`    | `/schema/ddl/:ddlId`          | 原生 DDL、阶段与已声明关联  | 无                                                    | 返回 DDL 列表并保留分类       |
| `portal-api`                  | `/api`                        | 接口操作与公开契约集合      | `view=operation`；可选 `contract`                     | 两种目录独立显示各自来源状态  |
| `portal-api-operation-detail` | `/api/operation/:operationId` | OpenAPI 操作说明            | `view=request`；可选 `response`、`error`、`source`    | 跳转关联契约、源码或功能      |
| `portal-api-contract-detail`  | `/api/contract/:contractId`   | 公开 wire schema 与类型说明 | `view=schema`；可选 `source`                          | 未关联操作时仍能独立阅读      |

`operationId` 参数是 Portal 的稳定资源 ID，不直接等于 OpenAPI 的 `operationId` 字段；OpenAPI 未填写该字段时仍有稳定详情入口。

### 全局工具与异常

| 路由名称           | 路径               | 页面职责               | 页内视图 / 默认值                | 导航行为                         |
| ------------------ | ------------------ | ---------------------- | -------------------------------- | -------------------------------- |
| `portal-search`    | `/search`          | 全量搜索结果           | 无                               | 命中进入资源自己的详情路径       |
| `portal-source`    | `/source`          | 数据源、当前索引和诊断 | `view=status`；可选 `diagnostic` | 诊断可定位对应来源与受影响页面   |
| `portal-not-found` | `/:pathMatch(.*)*` | 未知页面地址           | 无                               | 保留输入地址，提供概览和搜索入口 |

资源详情路径存在但 ID 已失效时，在详情布局显示“资源已不存在”。来源当前不可读、不能确认资源是否存在时，显示来源不可用或过期缓存，不误报删除。

## 4. URL 查询参数矩阵

| 页面范围                | 参数                                   | 值与默认                                              | 用途                                                                    |
| ----------------------- | -------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------- |
| 具有页内视图的页面      | `view`                                 | 见路由矩阵                                            | 页内导航，支持刷新和前进后退                                            |
| 进度集合                | `q`、`status`、`maturity`、`dimension` | 空为不限；多值以逗号分隔                              | 搜索功能生命周期、某个交付维度与程度；`maturity` 生效须指定 `dimension` |
| 功能 Issue 视图         | `status`                               | tracker 的原始状态，多值以逗号分隔                    | 筛选所属 Issue，不使用功能生命周期值                                    |
| 文档集合                | `q`、`kind`、`package`                 | 空为不限                                              | 搜索、文档分类和来源包                                                  |
| 结构集合                | `q`、`package`、`focus`                | 空为不限 / 不聚焦                                     | 树过滤、包范围和已存在节点定位                                          |
| 设计基础                | `token`                                | 已收录 token 名称                                     | 定位 token；仅在 token 视图使用                                         |
| 组件集合                | `q`、`layer`                           | `layer=ui` 或 `component`，空为不限                   | 只区分已收录的基元与通用功能组件                                        |
| 组件详情                | `example`                              | 已注册示例 ID；缺省采用来源声明的默认示例             | 保留示例选择，临时参数调整留本地                                        |
| Schema 集合             | `q`、`domain`、`stage`、`focus`        | `stage=init`、`schema` 或 `upgrade`；其余取已收录身份 | `domain` 来自声明；`stage` 只用于 DDL；`focus` 只用于 ER 图             |
| API 集合                | `q`、`tag`、`method`                   | 方法为大写，多值以逗号分隔                            | `tag` / `method` 仅用于操作目录                                         |
| 搜索结果                | `q`、`kind`、`package`                 | `q` 为查询文本，空时显示搜索说明                      | `kind` 使用资源设计中的类型值，支持多值                                 |
| 数据源状态              | `source`、`severity`                   | 来源 ID；`severity=info`、`warning` 或 `error`        | 来源聚焦和诊断筛选                                                      |
| 列表页面                | `sort`、`page`、`pageSize`             | 默认 `name-asc`、`1`、`20`；每页可选 20、50、100      | 仅对具有列表分页的视图有效；搜索默认按相关性排序                        |
| 文件详情 / 文档源码视图 | `line`                                 | 正整数，缺省不定位                                    | 进入源码时定位行；文档 preview 不使用该参数                             |
| 文档详情                | URL hash                               | 当前文档的标题锚点                                    | 正文目录定位；不存在时说明锚点失效，不判整个资源不存在                  |

进度 `status` 使用 `untracked`、`wontfix`、`unknown`、`done`、`in-progress`、`waiting`、`planned`。实现维度值为 `frontend`、`contract`、`backend`、`database`，实现程度值以业务设计为准。

`sort` 首版列表支持 `name-asc`、`name-desc`；具有明确来源更新时间的列表可增加 `updated-desc`，搜索支持 `relevance`。不能使用未收录的时间字段排序。分页参数不用于文件树、图谱、看板或详情正文。

同一参数在不同页面有不同适用范围，跨一级入口时不自动携带旧筛选。多值参数去重后按固定顺序编码，避免等价状态产生多个 URL。

## 5. 导航、历史与状态归属

### URL 与本地状态

- path 拥有资源身份，query 拥有视图、筛选、搜索和分页，hash 拥有正文锚点。
- 壳层拥有侧栏展开状态；浏览器本地偏好可保存展开与列展示，不写回仓库。
- 临时菜单、Tooltip、拖拽状态、图谱缩放、组件示例参数和当前文本选区留在本地。
- 图谱分享使用 `focus` 资源定位，不将整幅画布坐标序列化进 URL。
- 每页只有一份规范化路由状态；控件从它读写，避免 store 与 URL 各持一份筛选。

### push 与 replace

- 进入资源详情、切换页内视图、提交搜索或确认筛选、翻页使用 push。
- 搜索输入过程只更新本地草稿，提交或停顿后确认一轮筛选再更新 URL；不逐字符创建历史项。
- 初始重定向、移除无效参数、规范化默认值、筛选导致页码归一使用 replace。
- 明确的索引刷新不新增历史项；资源仍存在时保留当前 URL 与可用选择。
- 异步内容变化后滚动定位只执行一次，不能每次刷新都跳回命中行。

### 返回与滚动

- 浏览器后退恢复来源页面的 URL 状态和按完整 URL 保存的滚动位置；文档 hash 优先定位。
- 面包屑提供确定的父资源路径，不调用无条件 history.back；直接打开详情也能回到父集合。
- 不在 query 中放任意 `returnTo`。来源列表的精确返回依靠浏览器历史；列表缺省入口始终存在。
- 资源详情不以必须先打开列表的 Sheet 作为唯一入口；Sheet 可用于临时预览，永久链接仍指向详情路由。

### 全局搜索

顶部搜索入口和 Ctrl / Cmd + K 打开快速定位层；Esc 关闭并把焦点返回触发器。快速结果选择资源后关闭浮层并进入详情；“查看全部”进入 `/search?q=...`。

没有输入时显示搜索说明与可用资源类型，不伪造最近访问或搜索历史。搜索不可用时可跳到数据源状态，正常导航仍可使用。

## 6. 路由元信息与页面异常

实现时用统一路由定义维护名称、标题、所属 section、面包屑父级和导航可见性。侧栏、面包屑和快速导航消费相同定义，不分别维护入口清单。

资源标题来自成功解析的资源；未解析时使用“文档详情”等稳定页面名称，来源失败不能使面包屑空白。沿用前端现有静态路由导入约定；暂不为页面建立独立权限或任意插件注册机制。

| 情况                         | 页面行为                                          |
| ---------------------------- | ------------------------------------------------- |
| 无效 `view` / 枚举 query     | 回到该页默认状态，以 replace 移除无效值           |
| 无效分页数值                 | 回到合法默认值；筛选变化回到第一页                |
| 当前数据缩减导致页码越界     | 归一到最后合法页；没有结果时页码为 1              |
| 资源 ID 无法解析或确认不存在 | 资源失效说明，提供所属集合与搜索入口              |
| 数据源不可用且无缓存         | 来源说明、重试索引入口；不生成空成功结果          |
| 部分来源解析失败             | 呈现可用内容，并列出未覆盖范围                    |
| 快照过期                     | 保留可读内容，持续显示快照时间与过期原因          |
| 未知页面路径                 | 进入 `portal-not-found`，不自动重定向隐藏错误地址 |

## 7. 后续路由规划

下列路径只保留设计意图，P0 不注册路由、不展示禁用侧栏占位项，也不纳入首版路由验收。

| 导航项   | 规划入口       | 业务职责                                     | 引入前提                                   |
| -------- | -------------- | -------------------------------------------- | ------------------------------------------ |
| 变更关联 | `/change`      | 当前 diff 或选定版本涉及的资源及关联         | 有明确比较基线和可解释的关联分析           |
| 质量状态 | `/quality`     | 构建、类型检查、lint、测试和 CI 的版本化结果 | 检查报告与来源、时间、范围可以对应         |
| 开发环境 | `/environment` | 工具版本、服务、端口和启动说明               | 有明确只读探测与配置来源；执行能力另行设计 |

## 8. 路由验收

首版每条路由验证直达、刷新和导航归属；每种页内视图验证合法与非法 query、前进后退和默认值归一。至少覆盖文档 hash、源码行号、ER 图 focus、组件 example、搜索结果跳转、来源失败和已删除资源。

`/api` 必须返回 API 浏览页面，`/portal-api/*` 必须由仓库服务处理；未知仓库接口不能落入前端 history fallback。
