# P08 独立真实 Web 验收

日期：2026-10-22。接续 [P08 后端交付](../../packages/backend/docs/design/mvp-p08-2026-10-19.md) 和 [P08 前端隔离验收](../../packages/frontend/docs/remediation/2026-10-15/r04/facility-p08-acceptance-2026-10-19.md)。本轮补齐此前尚未签收的真实登录、设施维护、共享授权、存储结构与数据库联合 Web 验收，不增加业务范围。

**结论：P08 的独立本地 Web 验收缺口已补齐。15 组浏览器场景通过，最终数据库一致性核对通过，最终分组报告的 pageerror 列表均为空。本轮没有修改业务代码、公开契约或数据库结构。**

## 环境与数据边界

使用本机 Edge、真实前端完整应用壳层、HTTP 后端及 `test.local` 的 `talos-ark_backend_test`。临时后端为 `localhost:3118`，临时前端为 `localhost:4468`；没有复用或停止原有 3000/4444 开发服务。

复用三个已有合成账户，通过真实密码登录取得会话；数据库确认三者均不是超级管理员。本轮新建专用合成组织 `p08-web-1792617612038`，以及 A/B/C 三个工作区，分别验证管理、共享成员和未共享成员上下文。另建合成组织验证跨组织拒绝。组织、工作区和角色通过真实 API 创建；成员关系通过定向 SQL 准备，作为测试前提，不将本轮记为 P06 邀请流程验收。

专用组织 ID 为 `01a16056-0319-7328-ae50-503514113c52`。仅对该测试组织执行过一次受控权限缺项准备，用于验证显式初始化；测试后已恢复默认权限和成员原有角色，撤回临时设施共享关系。合成业务记录及审计历史保留，便于追溯。

没有操作 dev/prod、执行 Schema 同步或 DDL、清空数据库，也没有发送真实邮件。后台定时任务关闭。除“真实写入已提交后，拦截后续 GET 返回 503”的恢复测试外，没有用响应拦截替代设施业务数据或写入。

## 真实场景结果

以下 15 组均由真实页面、网络响应和持久化事实共同核对，不将按钮可见或前端禁用单独当成授权证明。

| 场景 | 已确认结果 |
| --- | --- |
| 1. 设施登记 | 普通组织所有者通过实际表单创建三个设施，详情刷新后仍存在 |
| 2. 容器与孔位 | 实际结构表单创建容器及 2 × 2 网格，生成四个从 1 开始的真实 POSITION；重读显示持久化坐标 |
| 3. 结构排序与空子树移动 | 页面完成同级排序，并将整个空盒及四个孔位移至另一设施；容器和孔位 ID 不变 |
| 4. USE 共享 | 管理页面授予工作区 B USE 后，普通成员可浏览和选择真实位置；不能创建节点，直接 HTTP 写入也返回 403 |
| 5. MANAGE 共享 | 页面将 B 的关系改为 MANAGE 后，具备动作权限的普通成员可创建层架；审计执行人是该成员 |
| 6. 撤权与隔离 | 页面撤回共享后，成员刷新清除结构和已选位置；旧节点 URL/详情接口被拒绝。未共享 C 工作区列表为空，跨组织访问被拒绝 |
| 7. 设施生命周期 | 空设施通过真实确认框完成停用、启用、归档、恢复，服务端状态与界面一致 |
| 8. 祖先状态与活动下级 | 含活动孔位的容器归档返回 409；停用祖先后四个孔位不再进入可用候选，恢复后重新出现 |
| 9. 叶容器生命周期 | 层架停用、启用、归档、恢复后身份不变，不通过删除重建实现恢复 |
| 10. 真实修订冲突 | 表单打开后由另一真实请求修改 revision；旧表单保存返回 409，保留草稿并阻止重复提交。显式刷新后由用户重新确认保存 |
| 11. 写后同步失败 | 真实 PATCH 成功后使后续 GET 失败；页面明确显示已成功但未同步，禁止重发。恢复只发 GET，该次修改只有一个 PATCH |
| 12. 显式权限初始化 | 从专用组织默认角色移除 facility.manage 后，读取 context 不修复权限；所有者在页面明确确认初始化后才补齐。重复初始化 updated=false，普通成员调用返回 403 |
| 13. 关系不替代动作权限 | 保留 MANAGE 共享但移除成员 facility.manage 动作权限后，页面不提供创建，直接创建接口返回 403 |
| 14. 管理工作区变更 | 实际编辑表单将空设施管理工作区 A 改为 B，再改回 A；B 的结构管理资格随真实管理关系获得和失去，没有虚构额外共享记录 |
| 15. 实际应用布局 | 1440/1024 宽度下查看持久化结构和网格；逐张检查截图，结构响应式排列，已检查的操作按钮未出现文字裁切 |

显式初始化测试只改变专用测试组织的角色，不修改共享代码中的默认权限定义。关系与动作权限的反向组合分别验证，避免超级管理员或组织治理入口掩盖普通工作区成员的访问规则。

## 证据与运行说明

本机忽略目录 `output/p08-acceptance-2026-10-22/` 保存一次性脚本、隔离编译产物、截图及结果，不新增永久测试框架。`browser.json`、`browser-sharing.json`、`browser-lifecycle.json`、`browser-recovery.json`、`browser-governance.json`、`browser-final.json` 共记录 15 组通过及空的 pageerror 列表；`database.json` 保存最终数据库事实与审计分类。请求记录不包含密码、Cookie 或令牌。

主要截图为 `final-grid-1440.png`、`final-grid-1024.png`、`member-use.png`、`member-revoked.png`、`write-sync-failed.png`。证据位于本机、不受 Git 跟踪，跨机器复核需单独交付。

并行日志重构影响了本轮正常构建/默认启动：声明生成出现 TS2883，默认采样分支出现 Pino hooks 初始化错误。本轮未修改该线程代码；使用独立输出目录，以 `--declaration false` 完成可执行编译及别名转换，并采用测试运行时的控制台 JSON/采样配置启动。该配置仅影响日志输出，不替代设施授权或业务实现。**本轮不签收最新工作树的完整标准构建，也不将上述日志问题计为已修复。**

临时服务日志另外出现过两条 `ResizeObserver loop completed with undelivered notifications`，以及 pg 关于同一 client 正在执行查询时再次调用 query 的弃用告警。最终分组 pageerror 为空不能解释为所有调试运行完全无告警；这些告警未阻断本轮业务断言，但未定位根因，仍需后续独立排查。

验收结束后已关闭本轮临时 3118/4468 服务；没有向原有开发服务发送停止命令。
